# 討伐者資格証 画像フォーマット デザイン指示書 v1.0

> キャラクターシートの情報を「討伐者資格証」として画像出力するためのデザイン仕様。
> 実装者（フロントエンド / 画像生成エンジン）向けの完全な指示書。

---

## 1. コンセプト

### 世界観上の位置づけ

討伐者資格証は、怪異討伐の資格を持つ者に発行される身分証明書。
世界観上は魔導省が管理する公的文書だが、実際には所属によって扱いが異なる。

| 所属 | 資格証の扱い |
|:-----|:------------|
| 祓部 | 正式な公的身分証。常時携帯義務あり |
| 傭兵 | 《Anonymous》の登録証と兼用。実質的な営業許可証 |
| 無所属 | 持っていない者も多い。偽造品も出回る |

### デザインの方向性

- **暗いHUD端末に表示される電子証明書** のイメージ
- 紙の証明書ではなく、端末やホログラムで投影されるデジタルカード
- 世界観の「走査線のリアリティ」に従い、微かなノイズ・グリッチ感を持つ
- 所属ごとに色調が変わるが、基本フォーマットは統一

## 2. 全体レイアウト

### 画像サイズ

| 用途 | サイズ | アスペクト比 |
|:-----|:------|:------------|
| 標準（SNS共有用） | 1200 × 630 px | 約 1.9:1（OGP互換） |
| 縦型（スマホ保存用） | 900 × 1600 px | 約 9:16 |
| 正方形（アイコン用） | 1080 × 1080 px | 1:1 |

**主要フォーマットは標準（1200×630）**。以下すべてこのサイズで設計する。

### レイアウト構造（1200×630）

```
┌────────────────────────────────────────────────────┐
│ HEADER BAR（40px）                                    │
│ 「電脳怪異譚 KAI-I//KILL — 討伐者資格証」              │
├──────────┬─────────────────────────────────────────┤
│          │  NAME BLOCK（上段）                         │
│  PORTRAIT │  キャラクター名（大）+ 二つ名/称号           │
│  AREA     │  所属バッジ + 配属 + 覚醒タイプ              │
│  (280×     ├─────────────────────────────────────────┤
│   340px)  │  ABILITY BLOCK（中段）                      │
│           │  体 疾 識 判 察 術 魂 の7値を横並び          │
│           ├─────────────────────────────────────────┤
│           │  DATA BLOCK（下段）                         │
│  ID &     │  背景 / 武器型 / ギフト / 装備              │
│  META     │  魔法言語 / 信念点 / サイバネティクス等級     │
├──────────┴─────────────────────────────────────────┤
│ FOOTER BAR（30px）                                    │
│ ID番号 + 発行日 + 承認状態バッジ                        │
└────────────────────────────────────────────────────┘
```

### グリッド（px単位の詳細）

```
全体：1200 × 630
余白：上下左右 20px

HEADER：   x=20, y=20,   w=1160, h=40
PORTRAIT： x=20, y=70,   w=280,  h=340
NAME：     x=320, y=70,  w=860,  h=90
ABILITY：  x=320, y=170, w=860,  h=100
DATA：     x=320, y=280, w=860,  h=130
ID/META：  x=20,  y=420, w=280,  h=170（ポートレート下）
```

## 5. 各ブロックの詳細設計

### 5-A. HEADER BAR

```
┌──────────────────────────────────────────────────┐
│ 電脳怪異譚 KAI-I//KILL          討伐者資格証 / HUNTER LICENSE │
└──────────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|:-----|:-----|
| 高さ | 40px |
| 背景 | `#0a0c10`。下辺に 1px の所属アクセント色ライン |
| 左テキスト | 「電脳怪異譚 KAI-I//KILL」 JetBrains Mono, 10px, `#555566` |
| 右テキスト | 「討伐者資格証 / HUNTER LICENSE」 JetBrains Mono, 10px, 所属アクセント色 |

### 5-B. PORTRAIT AREA

| 要素 | 仕様 |
|:-----|:-----|
| サイズ | 280 × 340px |
| 画像 | `thumbnail_url` または `image_url`。未設定時はシルエットプレースホルダー |
| フィット | `object-fit: cover; object-position: center top;` |
| 枠 | 1px solid 所属アクセント色（20%透過） |
| 角丸 | なし（直角） |
| プレースホルダー | 暗色背景 + 所属アクセント色の「?」文字（中央配置、80px） |

### 5-C. NAME BLOCK

```
┌─────────────────────────────────────────────┐
│ ▍架見・静流                                    │  ← キャラ名（36px, 白, Bold）
│   《静水》                                     │  ← 称号（16px, 所属色, Regular）
│                                                │
│  [祓部]  古怪班  先天覚醒型                      │  ← バッジ + 配属 + 覚醒
└─────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|:-----|:-----|
| キャラ名 | 36px, `#ffffff`, Bold。左に所属色の縦バー（4px×36px）を配置 |
| 称号 | 16px, 所属アクセント色, Regular。二重山括弧《》で囲む。`active_title` または `title` |
| 所属バッジ | 角丸4pxの矩形。背景=所属色（20%透過）、文字=所属色、JetBrains Mono 10px |
| 配属 | 14px, `#e8e6e3`, Regular |
| 覚醒タイプ | 14px, `#9a9a9a`, Regular |

### 5-D. ABILITY BLOCK

7つの能力値を横一列に均等配置する。

```
┌─────────────────────────────────────────────┐
│  // ABILITIES                                   │  ← ラベル（Mono, 10px, 所属色）
│                                                  │
│  体    疾    識    判    察    術    魂           │  ← 漢字（14px, 灰, Bold）
│  B     C+    B+    C+    D     C     D           │  ← ランク（28px, ランク色, Mono Bold）
│  ███▓  ██▓░  ███▓  ██▓░  █░░░  ██▓░  █░░░       │  ← バー（高さ4px）
└─────────────────────────────────────────────┘
```

1つの能力値ブロック（幅 約120px）：

| 要素 | 仕様 |
|:-----|:-----|
| 能力名（漢字） | 14px, `#9a9a9a`, Noto Sans JP Bold, 中央揃え |
| ランク文字 | 28px, ランク色, JetBrains Mono Bold, 中央揃え |
| +段階表示 | ランク文字の右上に小さく「+」（12px, 所属色） |
| ランクバー | 幅100px × 高さ4px。背景=`rgba(255,255,255,0.05)`、塗り=ランク色 |
| バー充填率 | D=20%, C=40%, B=60%, A=80%, S=100% |

### 5-E. DATA BLOCK

2列 × 3行のグリッドでデータ項目を配置する。

```
┌─────────────────────────────────────────────┐
│  // CHARACTER DATA                               │
│                                                  │
│  背景：鋼の肉体          武器型：斬撃型           │
│  ギフト：生還の意地       装備：蒼鉄制式剣         │
│  魔法言語：IGN / NGT      信念：●●●●●            │
│  サイバネ：等級Ⅰ         製造：蒼鉄機工           │
└─────────────────────────────────────────────┘
```

各データ項目：

| 要素 | 仕様 |
|:-----|:-----|
| ラベル | JetBrains Mono, 10px, `#555566`。末尾にコロン |
| 値 | Noto Sans JP, 14px, `#e8e6e3`, Medium |
| 魔法言語 | 得意言語を略称で列挙。各略称は対応する言語色で着色 |
| 信念点 | 黒丸●（所属色）×現在値 + 白丸○（灰）×残り |
| サイバネ等級 | Ⅰ/Ⅱ/Ⅲ または「なし」 |

### 魔法言語の略称と色

| 言語 | 略称 | 色 |
|:-----|:-----|:---|
| Igniscript | IGN | `#ff4444` |
| Lupis Surf | LPS | `#3070c0` |
| Ivyo | IVY | `#30a050` |
| NGT | NGT | `#c0a030` |
| Monyx | MNX | `#b0b0c0` |
| P: | P: | `#7030a0` |
| P' | P' | `#c06088` |

得意 = 略称を言語色で表示。苦手 = 略称に取り消し線 + 暗灰色。

### 5-F. ID / META BLOCK（ポートレート下）

```
┌──────────────┐
│ // ID          │
│ CHAR-xxxxxxxx  │  ← UUID先頭8桁
│                │
│ // STATUS      │
│ 年齢：24       │
│ 性別：男       │
│                │
│ // AUTHOR      │
│ @username      │
└──────────────┘
```

| 要素 | 仕様 |
|:-----|:-----|
| ID | `CHAR-` + UUID先頭8桁。JetBrains Mono, 11px, 所属色 |
| 年齢・性別 | Noto Sans JP, 12px, `#9a9a9a` |
| 投稿者名 | JetBrains Mono, 10px, `#555566` |

### 5-G. FOOTER BAR

```
┌──────────────────────────────────────────────────┐
│ ISSUED: 2026-03-15   STATUS: [公認]   BETA 0.1.0          │
└──────────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|:-----|:-----|
| 高さ | 20px |
| 背景 | なし（透過） |
| テキスト | JetBrains Mono, 9px, `#555566` |
| 発行日 | `created_at` をYYYY-MM-DD形式 |
| 承認バッジ | `approved_status` に応じて色分け |
| バージョン | 「BETA 0.1.0」固定 |

承認状態バッジ：

| 状態 | テキスト | 色 |
|:-----|:--------|:---|
| pending | TMP | `#555566` |
| approved | 公認 | 所属アクセント色 |
| rejected | 却下 | `#c04050` |

## 6. 装飾とエフェクト

### 走査線（Scanline）

画像全体に薄い水平線のオーバーレイをかける。

```
高さ2pxの半透明黒線を4px間隔で繰り返す
色: rgba(0, 0, 0, 0.08)
```

### ノイズ

画像全体に微かなノイズテクスチャを乗せる。

```
ノイズ強度: 3〜5%
ブレンドモード: overlay
```

### 所属グロー

カードの左辺に沿って所属色のグロー（光漏れ）を配置する。

```
位置: 左辺から0〜60pxの範囲
グラデーション: 所属色（15%透過） → 透明
```

### 枠線

カード全体を1pxの枠線で囲む。

```
色: rgba(255, 255, 255, 0.06)
角丸: なし（全て直角）
```

## 7. 所属別バリエーション

### 祓部バージョン

- 左辺ライン: 金 `#d4af37`
- 左グロー: 金の微光
- 所属バッジ: 「祓部」金文字 + 金枠
- ヘッダー右の「討伐者資格証」が金色
- 能力値Bランク以上のバーが金色で統一感が出る

### 傭兵バージョン

- 左辺ライン: 青 `#3a6ea5`
- 左グロー: 青い端末光
- 所属バッジ: 「傭兵」青文字 + 青枠
- ヘッダー右が青
- 能力値バーが青系で冷たい印象

### 無所属バージョン

- 左辺ライン: 灰 `#7a7a8a`
- 左グロー: ほぼなし（灰色の微光のみ）
- 所属バッジ: 「無所属」灰文字 + 灰枠
- ヘッダー右が灰
- 全体的にくすんだ印象。「公的ではない」感じ

## 10. 実装メモ

### 推奨技術

| 方法 | 利点 | 欠点 |
|:-----|:-----|:-----|
| **Canvas API（ブラウザ）** | フロントエンドで完結。即座にプレビュー | フォント読み込みの制御が難しい |
| **html-to-image / dom-to-image** | HTMLで組んでそのまま画像化 | 外部ライブラリ依存。フォント問題あり |
| **@vercel/og（サーバーサイド）** | OGP画像と兼用可。サーバーでフォント制御可 | JSXベースのレイアウト記述 |
| **Sharp + SVG（サーバーサイド）** | 最も自由度が高い。フォント埋め込み可 | 実装コストが高い |

### ファイル名規則

```
kaiii_license_{character_id先頭8桁}_{timestamp}.png
```

例: `kaiii_license_a1b2c3d4_20260315.png`

### メタデータ埋め込み

PNG の tEXt チャンクに以下を埋め込む（任意）：

```
Author: {author_name}
Title: KAI-I//KILL 討伐者資格証
Character: {character_name}
ID: {character_id}
Generated: {ISO 8601 timestamp}
```

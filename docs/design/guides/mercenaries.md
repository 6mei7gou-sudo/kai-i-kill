## 1. 《Anonymous》とは何か

《Anonymous》は傭兵の**仕事仲介ネットワーク**。軍隊でも企業でもない。

| 項目 | 内容 |
|:-----|:-----|
| 正体 | 傭兵向けの依頼仲介・情報交換・チーム編成を行うネットワーク |
| 拠点 | 各都市に支部。錆ヶ浜（西管区）が最大の集積地 |
| 登録 | 支部への直接訪問、または定期登録会 |
| 統率者 | いない。ネットワーク自体が自律的に機能する |
| 性格 | 匿名性・実力主義・信頼経済。名前ではなく実績で語る世界 |

### デザインの根本思想

> 「誰でもない者たちが、名を得ていく場所」

- 統一された制服はない。統一されたロゴすらも「控えめ」に使われる
- 《Anonymous》のブランドは「見せるもの」ではなく「知る者だけが読めるもの」
- 祓部が「国家の権威を示す金」なら、《Anonymous》は「暗がりに浮かぶ青い光」

## 2. ブランドカラーと配色

### 基本色

| 用途 | 色名 | Hex | 説明 |
|:-----|:-----|:----|:-----|
| **主色** | 傭兵青（ようへいあお） | `#3a6ea5` | 企業・技術力の象徴。冷静さと信頼性 |
| **副色** | 鉄灰（てつはい） | `#2a2a3a` | 傭兵の日常。装備・拠点の基調色 |
| **強調色** | 端末光（たんまつこう） | `#4a9eff` | 端末画面・ランク表示・デジタル要素 |

### 補助色（企業提携時に使用）

| 企業 | Hex | 傭兵装備での使い方 |
|:-----|:----|:-----------------|
| 雷禽重工 | `#c06020` | バック企業の証。装備の一部に焦橙のラインが入る |
| 蒼鉄機工 | `#3a5a8a` | 入手経路を問わず、蒼鉄製品は鋼青の刻印が残る |
| 鴉羽技研 | `#3a3a4a` | 目立たない。改造痕としてかすかに残る程度 |
| 蜃気楼工廠 | `#6a3060` | 闇市場経由。深紫の焼印が消せない |
| 銀鎚精機 | `#a0a0b0` | 銀の刻印は誇り。あえて見せる傭兵が多い |

### 配色原則

- **青+鉄灰**: 《Anonymous》公式の組み合わせ。支部の看板・端末UI・ランクカード
- **企業色+傭兵装備**: 企業ロゴはそのまま残す。塗りつぶしたり隠したりしない（後述）
- **個人色**: 傭兵は自由。ただし祓部の金 `#d4af37` だけは使わない（暗黙の了解）

## 3. 《Anonymous》ロゴ

### コンセプト

**「途切れた輪の中の斜線」** — 匿名・不完全・流動する存在

- 輪が途切れている = 閉じた組織ではない。出入り自由
- 斜線 = 「名前を消す」打ち消し線。匿名性の象徴
- 全体が傾いている = 正規の枠組みから外れた存在

### 構造

```
      ╱━━━━━╲
    ╱           ╲
   │     ╱       │
   │   ╱         │        ← 中央の斜線（左下→右上）
   │ ╱           │
    ╲
      ╲___        ← 右下が途切れている（開いた輪）

```

詳細：

- **外形**: 正円の約 270度分（右下の約90度が途切れている）
- **線の太さ**: 円弧・斜線ともに均一（2.5mm基準）
- **斜線**: 円の内径を左下から右上へ貫く。角度は正確に45度
- **斜線の端**: 円弧の内側に接するが、交差しない（わずかに隙間を空ける）
- **途切れの位置**: 4時〜7時の方向（右下）。端部は丸め処理なし（ぶつ切り）

### ステンシル設計

```
      ┏━━━━━━━━┓
    ╱              ╲
   │                │
   │    ╱           │     ← 斜線（45度）
   │  ╱             │
   │╱               │
    ╲
      ╲___          ← 途切れ（ブリッジ不要：もとから開いている）
          ↑
       開口部（約90度）
```

- **浮き島なし**。途切れた輪なので、すべてが外枠と接続している
- **斜線と円弧の接続**: 斜線の両端は円弧に近接するが接触しない（1mm程度の隙間）。ステンシルではこの隙間がブリッジ代わりになる
- **最小サイズ**: 15mm。斜線と円弧の隙間が潰れるため、小サイズでは斜線を円弧に接触させてよい
- **ステンシル難易度**: 低。浮き島もブリッジも不要

### サイズ展開

| 名称 | サイズ | 用途 |
|:-----|:------|:-----|
| フル | 40mm以上 | 支部の看板・壁面・端末起動画面 |
| 中 | 20〜39mm | ランクカード・名刺・装備の隅 |
| 小 | 10〜19mm | 通信機・ポーチ・弾倉 |
| 極小 | 10mm未満 | ICチップ刻印・データ透かし |

### 配色パターン

| 用途 | ロゴ色 | 背景 |
|:-----|:------|:-----|
| 支部看板・壁面 | 端末光 `#4a9eff` | 鉄灰 `#2a2a3a` |
| ランクカード | 傭兵青 `#3a6ea5` | 黒 `#0a0c10` |
| 装備への刻印 | 白 `#e8e6e3` | 素材地 |
| 端末UI | 端末光 `#4a9eff`（発光） | 暗色画面 |
| ステンシル塗装 | 白またはグレー | 装備色 |

### 使い方のルール

- 《Anonymous》ロゴは **控えめに** 使う。大々的に掲げるものではない
- 支部の入口に小さく、装備の目立たない場所に、端末の隅に
- 「知っている人には見える。知らない人には気づかれない」が理想
- ロゴを堂々と見せびらかす傭兵は **新人だとバレる**

## 4. ランク章・等級バッジ

### ランクカード

《Anonymous》登録者に支給されるIDカード。物理カード+デジタル証明の二重構造。

| 要素 | 仕様 |
|:-----|:-----|
| サイズ | 85.6mm × 54mm（標準カードサイズ） |
| 素材 | 黒色樹脂。表面マット仕上げ |
| 表面 | 左上に《Anonymous》ロゴ（小、端末光色）。中央にランクバー。右下にICチップ |
| 裏面 | 無地黒。磁気ストライプのみ |
| 名前 | **記載なし**。匿名ネットワークなので氏名欄は存在しない |

### ランク表示デザイン

ランクは横バーの本数と色で表現する。カードの中央に横線が並ぶミニマルなデザイン。

| ランク | 名称 | バー本数 | バー色 | 背景処理 |
|:-------|:-----|:---------|:-------|:---------|
| **E** | 見習い | 1本 | 鉄灰 `#2a2a3a` | なし |
| **D** | 一人前 | 2本 | 傭兵青 `#3a6ea5` | なし |
| **C** | 実戦級 | 3本 | 傭兵青 `#3a6ea5` | 左端に白ドット |
| **B** | 精鋭 | 4本 | 端末光 `#4a9eff` | 左端に白ドット2個 |
| **A** | 頂点 | 5本 | 白 `#e8e6e3` | バー全体が微発光 |
| **S** | 冠名 | バーなし | — | カード自体が存在しない |

```
Eランク:   ━
Dランク:   ━━
Cランク:  ●━━━
Bランク: ●●━━━━
Aランク:  ═════  （発光）
Sランク:  （カードなし。存在が証明）
```

### S ランク《冠名》について

- ランクカードは存在しない。S ランクは公式には存在しない等級
- 業界の総意として「あの人は冠名だ」と認められた者だけがそう呼ばれる
- 視覚的な証明はない。**実績と生存そのものが証明**
- デザイン上、Sランクを示すマークや色は定義しない。定義した瞬間に「匿名」の思想が壊れる

### 装備へのランク表示

ランクを装備に示す傭兵もいる。ただし強制ではない。

- 方法：装備の目立たない場所にバーをステンシルまたは刻印
- 位置：右肩・胸元・手首バンドなど（個人の好み）
- 色：白が多い。端末光の青を使う者もいる
- **Aランク以上は表示しない傭兵が多い**。見せる必要がないから

## 5. 企業ロゴの使われ方

### 根本ルール

> 傭兵の装備に付いている企業ロゴは「この装備を誰が作ったか」を示す。
> 「この傭兵が誰に属しているか」を示すものではない。

ただし現実には、装備の出所は関係性を暗示する。

### 企業ロゴの配置と意味

#### 雷禽重工（傭兵との関係が最も深い）

| 配置 | 意味 |
|:-----|:-----|
| 装備の側面に大きく | バック企業との公式契約。「雷禽が後ろにいる」という示威 |
| 装備の内部パーツに | 製造元表示のみ。特に関係を示さない |
| 装備の目立つ位置 + 傭兵集団の紋章 | 企業スポンサード部隊。最も攻撃的な組み合わせ |
| ロゴを塗りつぶしている | 関係が切れた、または切りたい。何かあった証拠 |

**雷禽装備の特徴的な見た目**:
- 焦橙 `#c06020` のアクセントライン
- 角張ったシルエット。鋭角的なエッジ
- 型番は機体に大きくステンシル（例：`RAIKIN-FA07`）
- 猛禽+稲妻のロゴがショルダーや胸部プレートに

#### 蒼鉄機工（本来は祓部専用だが…）

| 配置 | 意味 |
|:-----|:-----|
| 刻印が残っているが擦れている | 中古・払い下げ・闇市場流出品。出自を隠しきれていない |
| 刻印をヤスリで消した跡 | 祓部からの流出品を使っている。違法ではないがグレー |
| きれいな蒼鉄刻印 + 傭兵が使用 | 珍しい。蒼鉄が非公式に傭兵へ供給した可能性（政治的意味） |
| 祓部紋が消されて蒼鉄ロゴだけ残る | 「祓部の持ち物」ではなく「蒼鉄の製品」として使っている主張 |

**蒼鉄装備の特徴的な見た目**:
- 鋼青 `#3a5a8a` のマット仕上げ
- 丸みを帯びた安全設計。突起や鋭角が少ない
- 盾+歯車のロゴが控えめに刻印
- 管理番号の刻印跡がある（削られていても痕跡が残る）

#### 銀鎚精機（個人発注の一品物）

| 配置 | 意味 |
|:-----|:-----|
| 銀の刻印をあえて見せる | ステータスシンボル。「銀鎚に打ってもらった」という自慢 |
| 職人の個別マークが追加 | 世界に1つだけの証明。傭兵にとっての勲章に近い |

**銀鎚装備の特徴的な見た目**:
- 使い込まれた金属の質感。経年変化を「味」にする思想
- 銀灰 `#a0a0b0` の刻印が装備のどこかに必ずある
- 既製品には見えない微妙な非対称。手作業の証

#### 鴉羽技研（裏社会経由の改造品）

| 配置 | 意味 |
|:-----|:-----|
| 鴉羽のマークがかすかにある | 改造を受けた証。目立たない場所に小さく |
| 一切マークがない | 鴉羽技研が手を入れた装備は、痕跡を残さないことも多い |

**鴉羽改造品の特徴的な見た目**:
- 元の装備のシルエットを保ちつつ、内部が別物
- 外見からは改造の有無がわからない（それが売り）
- 稀に、グリップや接合部に暗炭色 `#3a3a4a` のカスタムパーツが見える

#### 蜃気楼工廠（闇市場の異物）

| 配置 | 意味 |
|:-----|:-----|
| 深紫の歪んだ六角形が焼きついている | 消せない。持っているだけで「手を出した」証拠 |
| 六角形を隠すカバーや布 | 所持を知られたくない。見せたら問題になる |

**蜃気楼装備の特徴的な見た目**:
- どこか「生っぽい」質感。金属なのに有機的な歪み
- 深紫 `#6a3060` の変色が素材に滲んでいる
- 使用者にも「変色」が移ることがある（設定上の怪異リスク）

## 6. 傭兵集団の独自マーキング

### 主要集団のビジュアル

#### 鉄蟲隊（てっちゅうたい）

| 項目 | 内容 |
|:-----|:-----|
| 紋章 | カブトムシの角を模した「V字」。太い線で力強く |
| 色 | 焦橙 `#c06020`（雷禽重工と同系。スポンサー色） |
| 配置 | 機体の両肩・車輌の側面に大きく。威圧的に |
| フォント | ゴシック体・太字。「TETSUCHU」を機体に |
| 印象 | 傭兵集団の中で最も「軍隊的」な見た目。統一感がある |

#### 白鷺調査社（しらさぎちょうさしゃ）

| 項目 | 内容 |
|:-----|:-----|
| 紋章 | 飛翔する白鷺のシルエット。優雅で細い線 |
| 色 | 白 `#e8e6e3`（清潔感。戦闘よりも調査を示す） |
| 配置 | 名刺・調査報告書のヘッダー。装備にはほぼ入れない |
| フォント | 明朝体。「白鷺調査社」の漢字表記 |
| 印象 | 傭兵というより探偵事務所。戦闘の匂いがしない |

#### 煙管組（きせるぐみ）

| 項目 | 内容 |
|:-----|:-----|
| 紋章 | 煙管（きせる）のシルエット。煙が立ちのぼる |
| 色 | 特定の色を持たない。各細胞（セル）が独自色を使う |
| 配置 | 統一されていない。煙管の刺青をしている構成員が多い |
| フォント | なし（漢字の「煙管」を筆文字で書くことがある） |
| 印象 | 統一感のなさ自体が特徴。「緩い集まり」であることの表れ |

#### 三日月旅団（みかづきりょだん）

| 項目 | 内容 |
|:-----|:-----|
| 紋章 | 三日月。左向き（東洋の月の描き方）。細い弧 |
| 色 | 銀白 `#c0c0d0`（月光の色。淡く控えめ） |
| 配置 | 袖口や襟元に小さく。車輌には月のステンシル |
| フォント | なし（紋章のみで運用） |
| 印象 | 放浪者の控えめな印。「ここにいたが、もういない」 |

### 独自マーキングのルール

- 傭兵集団のマーキングに公式ルールはない。**何でもあり**
- ただし以下は暗黙の了解として守られる：
  - 祓部紋を使わない（公的機関の詐称）
  - 他集団の紋章を使わない（信頼の破壊）
  - 蜃気楼工廠のロゴを堂々と見せない（危険人物とみなされる）
- 企業ロゴと集団紋章の **共存** は問題ない（むしろスポンサー関係を示す）

## 7. 二つ名の視覚表現

### 二つ名とは

実績を積んだ傭兵が業界から自然に呼ばれるようになる異名。
自称ではない。周囲が呼び始めて定着する。

### 視覚化のパターン

二つ名を持つ傭兵は、その名に由来するビジュアル要素を装備に取り入れることがある。

| 二つ名 | 視覚要素 | 装備への反映 |
|:-------|:---------|:------------|
| 鉄格子 | 格子模様 | 装甲表面に格子状の補強リブ。封印結界の意匠 |
| 紙雷 | 稲妻+紙片 | 装甲に白い稲妻模様。高速移動の軌跡を模したライン |
| 骨董屋 | 古道具 | 装備が意図的にレトロ。新品を古く見せる加工 |
| 鴉 | 黒い羽 | 全身黒。装備は最小限。視覚的な「空白」が特徴 |

### 二つ名のフォント指定

二つ名を文字として表記する場合：

| 用途 | フォント | スタイル |
|:-----|:--------|:---------|
| 装備への直接記載 | しない（二つ名は書くものではなく呼ばれるもの） |
| 《Anonymous》端末の表示 | モノスペース・Regular | 漢字+読み仮名 |
| 依頼書・契約書 | ゴシック体・Bold | 二つ名のみ（本名は記載しない） |

## 8. 装備の見た目と混在ルール

### 傭兵装備の「見た目の文法」

祓部は統一されている。傭兵は**混在している**。これが最大の視覚的差異。

```
祓部の装備:
┌─────────────────────────┐
│ 蒼鉄 + 蒼鉄 + 蒼鉄 + 蒼鉄 │  ← 全て同一メーカー。色も統一
└─────────────────────────┘

傭兵の装備:
┌─────────────────────────┐
│ 雷禽 + 蒼鉄(中古) + 銀鎚 + 鴉羽(改造) │  ← バラバラ。色も質感も不揃い
└─────────────────────────┘
```

### 混在のパターン別・印象

| パターン | 印象 | 推測される傭兵像 |
|:---------|:-----|:----------------|
| 全て雷禽重工 | 企業傭兵。スポンサーがいる。統一感 | 鉄蟲隊のような大規模集団 |
| 雷禽+蒼鉄混在 | 実用主義。使えるものを使う | Cランク以上の中堅 |
| 蒼鉄中古のみ | 予算不足か、元祓部。質実剛健 | Dランクか、脱退者 |
| 銀鎚の一品物 | 金がある。こだわりがある | Bランク以上。名のある傭兵 |
| 鴉羽改造品混じり | グレーゾーンに手を出している | 裏社会に近い。危険な仕事をしている |
| 蜃気楼製品あり | 何かを犠牲にしている | 異質。近寄りがたい |
| ほぼ素手/最小限 | 異能型。装備に頼らない | 鴉のような異能特化型 |

### 色の混在を描くときのポイント

- 傭兵の装備は **色が揃っていないのが正常**
- 同じ灰色でも、蒼鉄の鋼青灰と雷禽の暖灰では色温度が違う
- 新品と使い古しが混在する。経年変化のムラが傭兵らしさ
- テープ・布・塗料で応急的に補修した跡があると「現場の人間」感が出る

## 9. 支部・拠点の空間デザイン

### 《Anonymous》支部の雰囲気

支部は「事務所」ではなく「溜まり場」に近い。

| 要素 | 仕様 |
|:-----|:-----|
| 外観 | 雑居ビルの一室、倉庫の奥、地下の飲食店の裏。目立たない |
| 入口表示 | 《Anonymous》ロゴが小さく1つ。見つけられる人だけ来ればいい |
| 照明 | 暗め。端末の光が主光源。青白い光 `#4a9eff` が壁に反射 |
| 端末 | 壁面に埋め込まれた依頼確認端末。黒筐体+青UI |
| 掲示板 | アナログの掲示板も残っている。紙の依頼書が画鋲で留まっている |
| 什器 | 使い古されたカウンター、パイプ椅子、金属製のロッカー |
| 音 | 端末のハム音。低い会話。時々、装備がぶつかる金属音 |

### 錆ヶ浜の街並み

傭兵が最も集まる街。装備店が並び、情報が飛び交う。

- 看板は企業ロゴの洪水。雷禽の焦橙と蒼鉄の鋼青が混在
- 路地に銀鎚精機の小さな工房がある。看板は出さない（知る人だけが来る）
- 鴉羽技研の存在は噂でしか聞かない。仲介人に連絡するしかない
- 蜃気楼の痕跡は——見つけないほうがいい

## 10. 不文律とデザイン上の禁忌

### 傭兵社会の不文律

| 不文律 | デザインへの影響 |
|:-------|:----------------|
| 同じ現場に入ったら情報交換する | 敵味方の視覚区分がない。傭兵同士は「見た目で敵を判断しない」 |
| 依頼主の情報を売らない | 契約書に依頼主名がないことがある。「空欄」がデザイン要素になる |
| 過去を詮索しない | 経歴を示すマーキング（元祓部の紋章跡など）には触れない文化 |
| 私怨を持ち込まない | 個人的な装飾は自由だが、復讐を示すマーキングは嫌がられる |

### デザイン上の禁忌

| 禁忌 | 理由 |
|:-----|:-----|
| 祓部の金色 `#d4af37` を使う | 公的機関の色。傭兵が使うと詐称になる |
| 祓部紋を装備に入れる | 同上。即座に信頼を失う |
| 他の傭兵集団の紋章を無断使用 | 信頼経済の根幹を壊す行為 |
| 蜃気楼工廠のロゴを堂々と見せる | 危険人物認定。仕事が来なくなる |
| Sランクを自称する記号を作る | 冠名は他者が認めるもの。自称した時点で格が落ちる |
| 《Anonymous》ロゴを大きく派手に | ネットワークの匿名性を損なう。「新人か馬鹿」と思われる |

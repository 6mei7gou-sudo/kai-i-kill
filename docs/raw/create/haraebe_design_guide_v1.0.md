## 1. ブランドカラーと配色規則

### 基本3色

| 用途 | 色名 | Hex | 説明 |
|:-----|:-----|:----|:-----|
| **主色** | 祓金（はらえきん） | `#d4af37` | 国家権力・公的機関の象徴。紋章・階級章・公式文書に使用 |
| **副色** | 祓白（はらえしろ） | `#e8e6e3` | 神事の白。制服の基調色・祭祀衣装 |
| **地色** | 祓墨（はらえすみ） | `#1a1a2e` | 夜間作戦・戦闘服の基調色。暗闘時の隠匿性 |

### 補助色

| 用途 | 色名 | Hex | 説明 |
|:-----|:-----|:----|:-----|
| 警告・危険表示 | 朱 | `#c04050` | 禁域指定・侵食率警告・緊急通信 |
| 封印表示 | 深藍 | `#2a3a5a` | 封印班専用。封印状態の表示・結界マーク |
| 蒼鉄機工提携色 | 鋼青 | `#3a5a8a` | 蒼鉄機工納入装備に併用される色 |

### 配色原則

- **金+白**: 正装・式典・公式文書・紋章の第一配色
- **金+墨**: 戦闘服・装備マーキング・夜間作戦
- **白+墨**: 古怪班の儀式衣装（金は最小限に）
- **金は装飾に使わない**: 階級章・紋章・公印など「権威を示す箇所」のみに限定

## 2. 紋章・ステンシル

### 祓部紋（正紋）

**「丸に祓幣（はらえぬさ）」** — 祓いの儀式具を紋章化したデザイン

- **外形**: 正円の枠線（太さ均一 2.5mm）
- **中央モチーフ**: 祓幣（大麻 / おおぬさ）のシルエット。柄が下、紙垂（しで）が上に広がる
- **紙垂の処理**: 左右に2対（計4枚）の紙垂が稲妻形に折れ下がる。紙垂は伝統的なジグザグ折り
- **柄の処理**: 中心線1本。下端は円の内周に接する
- **全体の印象**: 神社の御幣を現代的に洗練した家紋形式

#### ステンシル構造

```
      ┏━━━━━━━━━┓
    ╱                ╲
   │    ╲╱  ╲╱      │    ← 紙垂（左右2対、ジグザグ）
   │   ╲╱    ╲╱     │
   │     │  │       │    ← 柄（中心の縦線2本）
   │      ││        │
    ╲     ││       ╱
      ┗━━━━━━━━━┛
```

- 紙垂のジグザグは **3段折り**。各折りの幅は均一
- 紙垂と柄の接続部にブリッジ1箇所（上部中央）
- ジグザグの内側に小さな浮き島が出る場合、左右にブリッジを追加
- 最小サイズ（20mm）では紙垂を2段に簡略化

#### サイズ展開

| 名称 | サイズ | 用途 | 省略事項 |
|:-----|:------|:-----|:--------|
| 正紋（フル） | 60mm以上 | 建物入口・車輌側面・公式文書 | なし |
| 中紋 | 30〜59mm | 装備本体・制服胸章・名刺 | 紙垂を2段に |
| 小紋 | 15〜29mm | 装備パーツ・弾倉底部・IDカード | 紙垂省略、円+柄のみ |
| 極小 | 15mm未満 | ボタン・ファスナー引き手 | 円のみ（中身なし） |

#### 配色パターン

| 用途 | 紋色 | 背景 |
|:-----|:-----|:-----|
| 正装・式典 | 金 `#d4af37` | 白 `#e8e6e3` |
| 戦闘服 | 白 `#e8e6e3` | 墨 `#1a1a2e` |
| 装備刻印 | 黒（刻印） | 素材地 |
| 公印（朱印） | 朱 `#c04050` | 紙面 |
| 金属装備 | エッチング（凹） | 金属地 |

### 略紋

紋章を極限まで簡略化した識別マーク。素早い識別が必要な場面で使用。

- **形状**: 縦長の菱形の中に、1本の縦線
- **意味**: 祓幣の柄を抽象化したもの
- **用途**: 弾帯・ポーチ・通信機の所属表示

```
    ◇
   ╱│╲
  ╱ │ ╲
  ╲ │ ╱
   ╲│╱
    ◇
```

## 3. 制服・戦闘服

### 3-A. 通常勤務服（庁内・事務）

| 部位 | 仕様 |
|:-----|:-----|
| 上衣 | 墨色（`#1a1a2e`）のスタンドカラージャケット。前合わせ5ボタン。ボタンは祓部極小紋入り |
| 襟元 | 左襟に階級章（金属製ピン）。右襟に管区章 |
| 袖 | 左上腕に祓部紋（中紋サイズ、金刺繍）。右上腕に班章 |
| 下衣 | 同色のストレートパンツ。ブーツインまたはストレート |
| 靴 | 黒の半長靴。金属トゥなし |
| 名札 | 右胸に氏名プレート（墨地に金文字、モノスペース体） |

### 3-B. 戦闘服（フィールド標準）

| 部位 | 仕様 |
|:-----|:-----|
| ベース | 墨色の耐衝撃コンバットスーツ。蒼鉄機工製。関節部に柔軟素材 |
| 防護 | 胸部・背部に軽量バリスティックプレート。蒼鉄機工の安全基準適合品 |
| 識別 | 左上腕に祓部紋（小紋、反射素材ではなくIR対応低視認素材） |
| 通信 | 右耳にインイヤー通信機。左手首にタクティカルバンド（状態表示） |
| 腰回り | 装備ベルト + サイドホルスター + ポーチ類。ポーチに略紋ステンシル |
| 靴 | 蒼鉄製タクティカルブーツ。脚部強化装甲との互換性あり |

### 3-C. 古怪班・儀式戦闘服

古怪班のみが着用する特殊装備。「白衣の異様な姿」として目撃報告に登場する。

| 部位 | 仕様 |
|:-----|:-----|
| 外衣 | 白（`#e8e6e3`）の狩衣風オーバーコート。袖は作業しやすいよう短め |
| 下層 | 標準戦闘服（墨色）をそのまま着用 |
| 防護 | 白衣の下にバリスティックベスト。外からは見えない |
| 帯 | 腰に紫紐の組紐帯。祓い道具（塩・酒・榊）の吊り下げ用 |
| 頭部 | なし（烏帽子は式典時のみ。実戦では非着用） |
| 足元 | 標準タクティカルブーツ（白足袋ではない） |
| 特記 | 白衣に祓部紋は入れない。「神事の装束に紋章は不要」という古怪班の信条 |

### 3-D. 正装（式典・公式行事）

| 部位 | 仕様 |
|:-----|:-----|
| 上衣 | 墨色のダブルブレストジャケット。金ボタン（祓部紋入り）8個 |
| 肩章 | 階級に応じた金モールの肩章 |
| 袖章 | 左袖に祓部正紋（金刺繍、60mm） |
| 右胸 | 勲功章・任務章の略綬バー |
| 手袋 | 白の礼装用手袋 |
| 特記 | 古怪班出身者は正装の下に白の襦袢を着ることがある（非公式な慣習） |

## 6. 武器命名規則

### 命名パターン

祓部の制式装備は以下の命名規則に従う。

```
[メーカー名] [機能・特性] [カテゴリ]【[型式名]】
```

#### 構成要素

| 要素 | 説明 | 例 |
|:-----|:-----|:---|
| メーカー名 | 製造元。制式品は「蒼鉄」 | 蒼鉄 |
| 機能・特性 | 強化、制式、戦術、封印、祓い用 など | 強化戦術 |
| カテゴリ | 剣、銃、ライフル、幣、符 など | 銃 |
| 型式名 | 【制式型】【狙撃型】【巡回型】【封印型】など | 【制式型】 |

#### 実例一覧

| 正式名称 | 分解 |
|:---------|:-----|
| 蒼鉄制式剣 | 蒼鉄 / 制式 / 剣 |
| 蒼鉄戦術ナイフ・制式 | 蒼鉄 / 戦術 / ナイフ / ・制式 |
| 蒼鉄強化戦術銃【制式型】 | 蒼鉄 / 強化戦術 / 銃 /【制式型】|
| 蒼鉄制式ライフル | 蒼鉄 / 制式 / ライフル |
| 祓い用幣【神道術式】 | — / 祓い用 / 幣 /【神道術式】|
| 術式封印符×10 | — / 術式封印 / 符 / ×10 |
| 偵察球体型【蒼鉄G-01】 | — / 偵察 / 球体型 /【蒼鉄G-01】|

### 独立型（ドローン・自律機）の型番規則

```
蒼鉄 [機能頭文字]-[世代番号]
```

| 頭文字 | 意味 | 例 |
|:-------|:-----|:---|
| G | General（汎用） | G-01 |
| D | Detection（索敵） | D-03 |
| A | Attack（攻撃） | A-05 |
| S | Support（支援） | S-02 |
| R | Recon（偵察） | R-07 |
| E | Electronic（電子戦） | E-01 |

世代番号は奇数が量産型、偶数が試作型。

## 7. 装備マーキング規則

### マーキング配置図（武装型の例）

```
銃身上面：      型式刻印（例：蒼鉄-T05-S）
銃身右側面：    祓部小紋 + 管理番号
銃身左側面：    蒼鉄機工ロゴ + 製造年月
グリップ底部：  配属管区コード
弾倉底部：      祓部極小紋
```

### 管理番号の書式

```
[管区番号]-[班コード]-[連番4桁]
```

| 管区番号 | 班コード | 例 |
|:---------|:---------|:---|
| 1〜5, HQ | KK=古怪, SK=新怪, FI=封印, KD=機動, TM=特務, GJ=技術 | 1-SK-0042 |

### フォント指定

装備のマーキングには以下のフォントを使用する。

| 用途 | フォント | スタイル |
|:-----|:--------|:---------|
| 型式名・管理番号 | モノスペース（等幅） | Regular / Bold |
| 漢字（紋章内） | 角ゴシック | Bold |
| 和名（神事装備） | 明朝体 | Regular |

### マーキング手法

| 手法 | 対象 | 特記 |
|:-----|:-----|:-----|
| レーザー刻印 | 金属装備・銃器 | 最も一般的。深さ 0.1mm |
| ステンシル塗装 | 車輌・大型装備 | 前項のステンシルガイド参照 |
| 刺繍 | 制服・布製品 | 金糸使用（正紋のみ） |
| エッチング | 刀剣類 | 酸による腐食。蒼鉄制式剣に適用 |
| 熱転写 | 樹脂・合成素材 | ポーチ・ベルト類 |

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓

┃  SPECIAL CASE COUNTERMEASURES BUREAU      ┃
┃━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┃
┃  文書種別：____                            ┃
┃  文書番号：HARAE-____-____               ┃
┃  日付：____年__月__日                      ┃
┃  機密区分：□一般 □部内限 □極秘          ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

### 文書番号の書式

```
HARAE-[管区]-[年度下2桁]-[連番5桁]
```

例: `HARAE-HQ-26-00142`（本庁・2026年度・142番）

### 機密区分

| 区分 | 表示 | 文字色 | 対象 |
|:-----|:-----|:------|:-----|
| 一般 | なし | — | 部外共有可 |
| 部内限 | 「部内限」 | 墨 `#1a1a2e` | 祓部内のみ |
| 極秘 | 「極秘」 | 朱 `#c04050` | 禊士以上のみ閲覧可 |
| 特秘 | 「特秘」 | 朱 + 金枠 | 大祓主・祓主のみ |

### 公印

- **形状**: 正方形（30mm角）の朱印
- **内容**: 「祓部之印」の4文字（篆書体）
- **用途**: 正式な命令書・辞令・許可証
- **管区印**: 同形式で「第○管区印」

## 10. 禁止事項・制限事項

### 絶対禁止

| 禁止事項 | 理由 |
|:---------|:-----|
| 祓部紋を傭兵・無所属の装備に使用 | 公的機関の詐称にあたる |
| 金色を階級章以外の装飾に使用 | 権威の形骸化を防ぐ |
| 戦闘服に個人的なペイント・デカール | 公的機関としての統一性 |
| 蜃気楼工廠の装備に祓部マーキング | 違法装備の公認化になる |
| 古怪班の白衣に紋章を入れる | 神事の装束は清浄であるべき（古怪班の信条） |
| 潜行班の存在を示す一切の識別物 | 存在自体が秘匿事項 |

### 制限付き許可

| 事項 | 条件 |
|:-----|:-----|
| 雷禽重工製装備の使用 | 正式には禁止だが、現場レベルで黙認されるケースあり。祓部紋は入れない |
| 個人カスタム装備 | 蒼鉄機工の安全基準内であれば可。改造検知センサーが作動すると本庁に通報される |
| 班別カラーの私物への使用 | 非公式の慣習として容認。公式には「班章は制服のみ」 |
| 退職者の紋章所持 | 退職時に返納が原則。実際は記念品として黙認されることが多い |

# KAI-I//KILL 企業ロゴ ステンシル制作ガイド v1.0

> 各企業のロゴをステンシル（型抜き）で再現するための設計資料。
> カッティング、スプレー塗装、シルクスクリーン、レーザー加工などに対応。

---

## ステンシル共通ルール

| 項目 | 仕様 |
|:-----|:-----|
| 推奨サイズ | 基準: 80mm角。最小: 30mm角（細部省略可）、最大: 300mm角 |
| ブリッジ幅 | 最小 1.5mm（浮き島が出ないよう接続線を確保する） |
| 線の太さ | 最小 2mm（カッター加工時）/ 1mm（レーザー加工時） |
| 余白 | ロゴ外周に最低 10mm のマージンを取る |
| 素材 | 厚紙（0.3mm）/ マイラーシート（0.1mm）/ アクリル板（2mm） |
| 塗料 | 下地色に合わせて各社ブランドカラーまたは単色（黒/白）を使用 |

### ブリッジの考え方

ステンシルでは「浮き島」（周囲から切り離された部分）が発生する。
例: 「O」の内側の丸、「A」の三角部分など。
これらは **ブリッジ**（細い接続線）で外枠とつないで保持する。
ブリッジの配置は左右対称にすると仕上がりが自然になる。

## 1. 蒼鉄機工（そうてつきこう）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 蒼鉄機工株式会社 |
| ブランドカラー | `#3a5a8a`（鋼青 / Steel Blue） |
| 設立 | 1900年代 |
| 性格 | 国家系・保守的・制式装備の老舗 |
| 顧客 | 祓部、国家機関 |

### ロゴコンセプト

**「盾の中の歯車」** — 安定・防御・精密工業の象徴

- **外形**: 五角形のシールド（盾）。上辺がやや広く、下に向かって尖る。角は丸めず直線で構成。
- **中央モチーフ**: 6歯の歯車。歯車の内側に「鉄」の漢字を幾何学的に簡略化した形状を配置。
- **下部テキスト**: シールド下辺に沿って「SOUTETSU」をセリフ体で弧状に配置。
- **全体の印象**: 官公庁の紋章に近い堅実さ。装飾は最小限。

### ステンシル設計の注意

```
┌─────────────┐
│  ╱─────────╲  │  ← 盾の上辺（広い）
│ │           │ │
│ │   ⚙ 鉄   │ │  ← 歯車 + 「鉄」の簡略形
│ │           │ │
│  ╲    ▽    ╱  │  ← 盾の下部（尖る）
│   SOUTETSU    │  ← 弧状テキスト
└─────────────┘
```

- 歯車の **中心穴** は浮き島になるため、12時・6時方向にブリッジを入れる
- 「鉄」の簡略形は横線3本+縦線1本の十字ベース。閉じた空間が生まれないよう線を途切れさせる
- 盾の輪郭は太線（3mm以上）で安定感を出す
- 最小サイズ（30mm角）ではテキスト省略、盾+歯車のみ

### 配色パターン

| 用途 | ロゴ色 | 背景色 |
|:-----|:------|:------|
| 制式装備の刻印 | 黒 `#000000` | 金属地 |
| 書類・公式文書 | 鋼青 `#3a5a8a` | 白 `#ffffff` |
| 暗色背景用 | 白 `#e8e6e3` | 暗色任意 |

## 2. 雷禽重工（らいきんじゅうこう）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 雷禽重工業株式会社 |
| ブランドカラー | `#c06020`（焦橙 / Burnt Orange） |
| 設立 | 1973年 |
| 性格 | 独立系・高出力・攻撃的 |
| 顧客 | 傭兵組織、独立系討伐機関 |

### ロゴコンセプト

**「雷光を掴む猛禽」** — 速度・出力・突破力の象徴

- **外形**: 正円なし。鋭角を多用した非対称ダイヤモンド形（菱形を左右に引き伸ばした形）。
- **中央モチーフ**: 翼を広げた猛禽のシルエット。翼端は稲妻状にギザギザに処理。頭部は右向き（前進方向）。
- **稲妻ライン**: 猛禽の胴体を貫くように1本の稲妻が垂直に走る。
- **テキスト**: 右翼の下に「RAIKIN」をサンセリフ体・イタリック（斜体）で配置。
- **全体の印象**: スポーツカーのエンブレムに近い。動的で攻撃的。

### ステンシル設計の注意

```
         ╱╲
    ╱╱╱╱    ╲╲╲╲       ← 翼（左右に鋭く伸びる）
   ╱  ╱  ⚡  ╲  ╲      ← 中心に稲妻ライン
  ╱  ╱  鳥体  ╲  ╲     ← 猛禽シルエット
   ╲╲╲╲    ╱╱╱╱       ← 下翼
         ╲╱
       RAIKIN           ← 斜体テキスト
```

- 猛禽の **翼と胴体の間** に細い隙間が生じやすい。翼は胴体と1箇所以上で接続させる
- 稲妻ラインは直線の折れ線（曲線禁止）。折れ角は45度固定で統一
- 翼端のギザギザは3段まで（小サイズでは1段に簡略化）
- 左右非対称だが、上下は鏡像に近い構成にする

|:-----|:------|:------|
| 装備への焼印 | 焦橙 `#c06020` | 金属地 |
| 戦闘機体マーキング | 白 `#ffffff` | 暗灰 `#2a2a2a` |
| 広告・カタログ | 焦橙 `#c06020` | 黒 `#0a0c10` |

## 3. 鴉羽技研（からすばぎけん）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 鴉羽技研（登記上は改造・修理サービス業） |
| ブランドカラー | `#3a3a4a`（暗炭 / Dark Charcoal） |
| 設立 | 2010年代 |
| 性格 | 裏社会寄り・低姿勢・信頼ベース |
| 顧客 | 無所属、闇市場隣接、一部傭兵 |

### ロゴコンセプト

**「一枚の鴉羽」** — 秘匿・軽さ・痕跡を残さない存在

- **外形**: ロゴ全体が1枚の羽のシルエット。縦長の楕円に近いが、羽軸で左右非対称。
- **中央モチーフ**: 羽軸（中心線）が上から下に貫く。軸の中央に小さな目（鴉の目）を1つ配置。瞳は塗りつぶし。
- **羽の処理**: 左側の羽弁はやや短く不揃い、右側は整っている（左右非対称で「裏社会」感を出す）。
- **テキスト**: なし。ロゴマークのみで運用。必要時は下部に「K.G.」の2文字のみ。
- **全体の印象**: 一見すると装飾パーツに見える。ロゴだと気づかれにくいデザイン。

### ステンシル設計の注意

```
        │
       ╱│╲
      ╱ │ ╲
     ╱  ◉  ╲        ← 鴉の目（塗りつぶし丸）
    ╱  ╱│╲  ╲
   ╱  ╱ │ ╲  ╲      ← 羽弁（左：不揃い / 右：整列）
  ╱  ╱  │  ╲  ╲
     ╱  │  ╲
        │
```

- 最もシンプルな構成。浮き島が **ほぼ発生しない**（目の部分のみ注意）
- 鴉の目は塗りつぶし円なので、ステンシルでは **穴を開ける** だけでよい
- 羽弁の線は細め（1.5mm〜2mm）。粗い仕上がりがむしろ「らしさ」になる
- 小サイズでは羽弁の細かい分岐を省略し、外形シルエットのみにする
- 意図的に「雑に吹く」ことで裏社会感が増す

### 配色パターン

| 用途 | ロゴ色 | 背景色 |
|:-----|:------|:------|
| 装備への刻印 | 暗炭 `#3a3a4a` | 素材地そのまま |
| 取引時の識別 | 白 `#e8e6e3` | 黒布・黒革 |
| 最小限マーキング | 黒 `#000000` | 任意（目立たない場所に） |

## 4. 蜃気楼工廠（しんきろうこうしょう）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 蜃気楼工廠（実体不明） |
| ブランドカラー | `#6a3060`（深紫 / Deep Purple） |
| 設立 | 不明 |
| 性格 | 正体不明・怪異核素材・危険 |
| 顧客 | 闇市場、出所不明の依頼者 |

### ロゴコンセプト

**「歪んだ六角と核の眼」** — 蜃気楼（幻影）・怪異・境界の侵食

- **外形**: 正六角形をベースに、各辺を微妙に歪ませた不正六角形。まるで熱で歪んだかのような揺らぎ。
- **中央モチーフ**: 六角の中心に「核」を表す同心円（2重円）。内円の中に縦のスリット（瞳孔）。怪異の「目」を暗示。
- **歪みの表現**: ステンシルでは直線を2〜3mm程度ずらして「ブレ」を再現。辺ごとにずらす方向を変える。
- **テキスト**: なし。刻印は六角形のみ。真贋不明の「蜃気楼」の印として機能する。
- **全体の印象**: 見る者に不安を与える。正確に描けない（描くべきでない）デザイン。

### ステンシル設計の注意

```
      ╱‾‾‾‾╲
     ╱       ╲
    │  ◎ ┃   │      ← 同心円 + 縦スリット（核の眼）
    │         │
     ╲       ╱
      ╲____╱
   ※各辺を微妙に歪ませる
```

- 同心円の **内円** は浮き島。上下にブリッジを入れるが、ブリッジ自体も歪ませる
- 外形の歪みは **意図的** なもの。製作時のブレではなく、設計段階で辺をずらす
- 「完璧に再現しない」ことがコンセプト。個体差が出てもよい（むしろ正解）
- 縦スリット（瞳孔）は六角形の高さの40%の長さ、幅2mm
- 深紫は暗い色のため、明るい下地（白・金属地）に映える

| 用途 | ロゴ色 | 背景色 |
|:-----|:------|:------|
| 闇市場の製品刻印 | 深紫 `#6a3060` | 素材地 |
| 焼印・腐食マーキング | 焦げ跡（素材変色） | 金属地 |
| 識別用 | 深紫 `#6a3060` | 黒 `#0a0c10` |

## 5. 銀鎚精機（ぎんつちせいき）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 銀鎚精機 |
| ブランドカラー | `#a0a0b0`（銀灰 / Silver Gray） |
| 設立 | 2010年代 |
| 性格 | 職人集団・一品物・高級路線 |
| 顧客 | 個人傭兵、無所属、富裕層 |

### ロゴコンセプト

**「金床の上の鎚」** — 鍛造・一点物・職人の誇り

- **外形**: 正方形に近いが下辺だけ広い台形（金床を暗示）。
- **中央モチーフ**: 逆さの鎚（ハンマー）。柄が上、頭部が下。頭部は金床のラインと一体化。
- **刻印スタイル**: ハンマーヘッドの平面に職人ごとの個別マーク（ステンシルでは共通形を使用）。
- **テキスト**: 台形の下辺に沿って「GINZUCHI」をセリフ体・キャピタルで配置。
- **全体の印象**: 刀鍛冶の銘に近い。見た者に「打った人間がいる」ことを意識させる。

### ステンシル設計の注意

```
     ┃      ┃
     ┃  柄  ┃         ← ハンマーの柄（細い縦棒）
    ┏┻━━━━━━┻┓
    ┃ ハンマー頭 ┃      ← ハンマーヘッド（横長の矩形）
   ┏┻━━━━━━━━┻┓
   ┃  GINZUCHI  ┃     ← 金床ライン + テキスト
   ┗━━━━━━━━━━┛
```

- 構造がシンプルで浮き島なし。ステンシル向き
- ハンマーの柄は細い（2mm幅）ので、カット時に折れないよう注意
- 金床部分（台形下部）は太線（4mm以上）で重量感を出す
- 高級感を出すため、線はすべて直線・直角。曲線は使わない

## 6. 羅刹技研（らせつぎけん）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 羅刹技研 |
| ブランドカラー | `#20c0a0`（電翠 / Electric Teal） |
| 設立 | 2020年代 |
| 性格 | AI特化スタートアップ・先端技術 |
| 顧客 | 傭兵組織、祓部（非公式） |

### ロゴコンセプト

**「回路の鬼面」** — AI・演算・魔法と機械の融合

- **外形**: 正円。外周はプリント基板のパターン（直角の配線）で構成。円の上部に2本の角（鬼の角）が突き出す。
- **中央モチーフ**: 鬼の顔の超簡略化。目は2つの小さな正方形（ピクセル）。口は水平の直線1本。顔全体が回路図のように直線のみで構成。
- **角の処理**: 角は直線の折れ線で構成（曲線なし）。各角は3つの屈折点を持つ。
- **テキスト**: 円の外周下部に「RASETSU」をモノスペース体で配置。
- **全体の印象**: テクノロジー企業のロゴだが、よく見ると鬼面。デジタルと和の融合。

### ステンシル設計の注意

```
       ╱╲   ╱╲         ← 角（直線の折れ線）
      ╱  ╲ ╱  ╲
    ┏━━━━━━━━━━━┓
   ╱  ■      ■   ╲     ← 目（正方形2つ）
  │                │
  │    ─────────   │    ← 口（水平線1本）
   ╲              ╱
    ┗━━━━━━━━━━━┛
      ═══════════       ← 回路パターン外周
       RASETSU
```

- 目の正方形は **穴を開ける** だけ（浮き島なし）
- 外周の回路パターンは細線（1.5mm）で描く。小サイズでは省略して単純な円にする
- 角は外形から突き出すため、ステンシルの外枠を角の先端まで広げる
- 口の水平線は左右の円弧と接続すること（浮き島防止）

## 7. 朱鷺崎財閥・技術部門（ときさきざいばつ）

### 基本情報

| 項目 | 内容 |
|:-----|:-----|
| 正式名称 | 朱鷺崎財閥 技術部門 |
| ブランドカラー | `#c04050`（朱鷺色 / Ibis Red-Pink） |
| 設立 | 1800年代後半 |
| 性格 | 旧財閥・秘匿主義・古い力 |
| 顧客 | 国家政府、独立傭兵、一部海外機関 |

### ロゴコンセプト

**「丸に朱鷺の羽」** — 家紋・伝統・隠された格式

- **外形**: 丸（正円の枠線）。日本の家紋の形式に準拠。線は均一な太さ。
- **中央モチーフ**: 朱鷺（トキ）の羽を3枚、中心から120度間隔で放射状に配置（三つ巴の変形）。羽の先端は円の内周に接する。
- **簡略度**: 家紋と同じく極限まで抽象化。羽は曲線1本+先端の膨らみで表現。
- **テキスト**: なし。家紋として単体運用。公式文書にのみ「朱鷺崎」の楷書を添える。
- **全体の印象**: 歴史の重み。「企業ロゴ」ではなく「家紋」。格が違うことを暗示。

### ステンシル設計の注意

```
      ┏━━━━━━━┓
    ╱   ╲ ╱ ╱    ╲
   │   ╱ ╳ ╲      │    ← 3枚の羽が中心から放射
   │  ╱     ╲     │       （三つ巴の変形）
    ╲          ╱
      ┗━━━━━━━┛
```

- 三つ巴構造のため、**中心部に浮き島** が発生しやすい。3枚の羽を中心点で接続する
- 円の枠線は均一太さ（2.5mm）。家紋の品格を保つため太すぎず細すぎず
- 羽の曲線は滑らかなカーブ。ステンシルでは3〜4点の折れ線で近似する
- 「完璧な対称」が重要。他社のような「味のある歪み」は厳禁
- 最も格式の高いロゴ。丁寧な仕上げが求められる

## 制作の流れ

1. **下書き**: 方眼紙にブランドカラーで参考スケッチを描く
2. **清書**: PCまたは手書きで正確な輪郭線を引く。ブリッジ位置を決定
3. **型紙作成**: 厚紙またはマイラーシートに転写し、カッターで切り抜く
4. **テスト塗装**: 不要な素材にテスト吹き。ブリッジの強度とにじみを確認
5. **本番**: 対象物に固定し、薄く複数回に分けて塗装

## 注意事項

- 蜃気楼工廠のロゴは「完全な再現」を目指さないこと。個体差があるのが正しい姿
- 鴉羽技研のロゴは目立たない場所に小さく入れるのが世界観に沿った使い方
- 朱鷺崎財閥のロゴは最も格式が高い。雑な仕上げは世界観を損なう
- 雷禽重工のロゴは機体マーキングとして大きく使うのが映える
- 銀鎚精機は製品ごとに職人の個別刻印が追加される設定。共通ロゴ+個別印の2層構造

## 1. 無所属の視覚的定義

### 核心

> 「何にも属さない者」は、何の紋章も持たないことで識別される。

祓部には金の紋章がある。傭兵には《Anonymous》がある。
無所属には——**何もない**。この「何もなさ」こそが無所属の視覚的アイデンティティ。

### 三原則

| 原則 | 説明 |
|:-----|:-----|
| **不統一** | 装備の色・メーカー・年代がバラバラ。揃っていたら無所属ではない |
| **不完全** | どこかが壊れている、欠けている、仮修理されている。完璧な状態は無所属の現実と合わない |
| **不可視** | 目立たない。目立てない。目立ったら追われる |

## 2. カラーと「色の不在」

### 公式デザイントークン

| 用途 | 色名 | Hex | 説明 |
|:-----|:-----|:----|:-----|
| 所属色 | 灰 | `#7a7a8a` | 帰属なし・自由。UIやバッジの所属表示に使用 |

これだけ。無所属には「ブランドカラー」が存在しない。

### 装備に現れる色

無所属の装備は自分の色ではなく、**他者の色の残骸**で構成される。

| 見える色 | 出典 | 意味 |
|:---------|:-----|:-----|
| 鋼青 `#3a5a8a` が擦れている | 蒼鉄機工の中古品 | 祓部の払い下げか横流し |
| 焦橙 `#c06020` のライン | 雷禽重工の断片 | 傭兵から流れた部品 |
| 暗炭 `#3a3a4a` のパーツ | 鴉羽技研の改造 | 裏社会との接点がある |
| 深紫 `#6a3060` の滲み | 蜃気楼工廠の焼印 | 手を出してはいけないものに触れた |
| 銀灰 `#a0a0b0` の刻印 | 銀鎚精機の一品物 | 極めて珍しい。裕福か、大きな借りがある |
| 錆色・土色・くすんだ灰 | 出所不明 | 自作・拾得・廃棄品。最も「無所属らしい」 |

### 色の原則

- **鮮やかな色は使わない**。鮮やかさ＝組織力・資金力の証
- **金色は絶対に使わない**。金＝祓部の国家権力
- **清潔な白も避ける**。白＝古怪班の神事装束
- 無所属の色は **くすんでいる、褪せている、汚れている**

## 3. 禁止事項一覧

無所属のデザインで「やってはいけないこと」を優先度順に列挙する。

### S級禁止（世界観を壊す）

| # | 禁止事項 | 理由 |
|:--|:---------|:-----|
| S1 | **祓部紋（祓幣の紋章）を装備に入れる** | 公的機関の詐称。現実なら即逮捕 |
| S2 | **祓部の金色 `#d4af37` を使う** | 国家権力の色。傭兵ですら避ける |
| S3 | **蒼鉄機工の管理番号がきれいなまま残っている** | 正規品は祓部が管理。きれいな番号＝盗品か偽造 |
| S4 | **統一された制服を着ている** | 無所属は「組織」ではない。制服は矛盾 |
| S5 | **《Anonymous》のランクカードを持っている** | ランクカード保持＝傭兵登録済み。無所属ではなくなる |
| S6 | **新品の蒼鉄製装備を身につけている** | 入手経路がない。祓部か闇市場からの盗品としか思えない |

### A級禁止（強い違和感を生む）

| # | 禁止事項 | 理由 |
|:--|:---------|:-----|
| A1 | **装備が全て同一メーカー** | 安定した供給元がある＝組織に属している証拠 |
| A2 | **装備に損傷・修理跡が一切ない** | 整備部門がない無所属の装備が完璧なのは不自然 |
| A3 | **企業ロゴを堂々と表に出す** | 企業との正式関係がないのにロゴを見せる意味がない |
| A4 | **蜃気楼工廠のロゴを隠さず見せる** | 所持が知られれば祓部と傭兵の両方から追われる |
| A5 | **清潔感のある服装** | メンテナンスの余裕がないのが無所属の現実 |
| A6 | **大型搭乗型を所有している（説明なしに）** | 維持費・整備・保管場所の全てが無所属には困難。所有するなら重い背景が必要 |

### B級注意（避けたほうがよい）

| # | 注意事項 | 理由 |
|:--|:---------|:-----|
| B1 | **色が統一されている** | 無意識に「所属感」が出る。バラバラが正解 |
| B2 | **高級感のある素材** | 無所属に高級品は手に入りにくい |
| B3 | **傭兵集団の紋章を使う** | 信頼経済を壊す行為。傭兵社会から排除される |
| B4 | **階級を示す記号がある** | 階級構造がない。あるとしたら偽装か元の所属の痕跡 |
| B5 | **最新型のサイバネティクス** | 正規の施術を受けられない。闇医者の古い技術が現実的 |

## 4. 装備の見た目 — 混沌の文法

### 「正しい無所属の装備」はこう見える

```
 ┌──────────────────────────────────┐
 │ 右肩：雷禽製の肩当て（焦橙が褪色）       │
 │ 胸部：蒼鉄の防弾プレート（管理番号が削られている）│
 │ 左腕：鴉羽技研で改造されたグローブ（暗炭色）   │
 │ 腰：民生品のベルト + 自作ポーチ（布製・手縫い） │
 │ 右脚：何かの装甲板をガムテープで巻いたもの     │
 │ 左脚：普通のブーツ（ソールがすり減っている）    │
 │ 武器：出所不明の銃（型番不明・テープ巻き）     │
 └──────────────────────────────────┘
```

### 質感のルール

| 要素 | 無所属らしさ | 避けるべき表現 |
|:-----|:------------|:-------------|
| 金属部品 | 擦り傷、錆、塗装剥げ | ピカピカの光沢 |
| 布・革 | 継ぎ当て、色褪せ、ほつれ | 新品の質感 |
| 接合部 | ガムテープ、針金、溶接跡 | きれいなネジ留め |
| 塗装 | ムラ、下地が透ける、色違いの重ね塗り | 均一なスプレー塗装 |
| 電子部品 | 配線むき出し、コネクタ不一致 | きれいな配線処理 |

### 修理跡の種類

修理跡は無所属の「履歴書」。どう直したかで背景が読み取れる。

| 修理方法 | 示唆する背景 |
|:---------|:------------|
| 溶接が上手い | 元技術者か、技術班出身 |
| 縫い目がきれい | 手先が器用。在野研究者や退魔師に多い |
| ガムテープ・結束バンド | 応急処置しかできない。路地裏の犬、脱走兵 |
| 木材や布で補強 | 現地調達。山間部や禁域近くで活動 |
| 怪異素材で補修 | 危険。蜃気楼工廠との接点がある可能性 |

## 5. 他勢力の痕跡 — 読み取れる過去

無所属の装備には「前の持ち主」の痕跡が残る。
この痕跡の処理方法が、キャラクターの過去を物語る。

### 痕跡の処理パターン

| 処理 | 意味 | 心理 |
|:-----|:-----|:-----|
| **削り取られている** | 過去を消したい | 元祓部の脱走兵。追われている |
| **塗りつぶされている** | 隠しているが完全には消せない | 所属を捨てたが未練がある |
| **そのまま残っている** | 気にしていない、または気づいていない | 拾い物をそのまま使っている |
| **わざと見せている** | 挑発、または実力の証明 | 「祓部から奪った」という示威 |
| **上から自分の印を重ねている** | 所有権の主張 | 過去を塗り替えて自分のものにした |

### 具体例

| 元の所属 | 残る痕跡 | 無所属での見え方 |
|:---------|:---------|:----------------|
| 祓部 | 管理番号の跡、祓部紋のくぼみ | ヤスリ痕が光る。「消そうとした」のが見える |
| 傭兵（雷禽系） | 焦橙の塗装下に別の色 | 上塗りしたが角や傷口から元色が覗く |
| 傭兵（銀鎚） | 銀の刻印 | 消す人はいない。「すごいもの持ってるな」と思われる |
| 鴉羽技研 | ほぼ痕跡なし | 改造箇所は外見からわからない。それが鴉羽の仕事 |
| 蜃気楼工廠 | 深紫の変色 | 布で巻いて隠す。触れさせない |
| 民生品 | ブランドタグ、バーコード | 日用品を戦闘用に転用した証拠 |

## 6. サイバネティクスの制約

### 正規ルートは閉ざされている

| ルート | 利用可否 | 理由 |
|:-------|:--------|:-----|
| 蒼鉄機工（正規） | 不可 | 祓部の承認が必要。門前払い |
| 雷禽重工（高出力） | 困難 | 傭兵集団経由なら可能だが、テレメトリで位置が筒抜け |
| 銀鎚精機（一品物） | 理論上可能 | 金と紹介者があれば。現実的にはほぼ不可能 |
| 鴉羽技研（改造） | 主要ルート | 闇医者と連携。品質保証なし。死亡リスクあり |
| 蜃気楼工廠（怪異核） | 禁忌 | 教団との接触が必要。人間でなくなっていく |

### 闇医者の施術の見た目

| 特徴 | 正規施術との違い |
|:-----|:----------------|
| 手術痕が大きい | 精密な手術機器がない |
| 接合部が不均一 | パーツの規格が合っていない |
| 皮膚との境界が荒い | 拒絶反応の抑制が不完全 |
| 配色がバラバラ | 在庫から使えるものを使う |
| 異音がする | 調整が甘い。動作時にきしむ |
| 古い世代の部品 | 最新パーツは闇市場に流れにくい |

### デザイン上の表現

- サイバネティクス部位は **きれいに見えてはいけない**
- 皮膚と機械の境界に **赤み・腫れ・変色** があるのが自然
- パーツの色が肌と合っていない（色合わせの余裕がない）
- 機械部品に **手書きのメモやマーキング** が貼ってあることがある（闇医者のメモ）

## 7. 類型別ビジュアル指針

### 各類型の「見た目の方向性」

#### 野良討伐者（のらとうばつしゃ）

| 要素 | 指針 |
|:-----|:-----|
| 体格 | 鍛えられている。装備より体が頼り |
| 装備量 | 少ない。身軽さ優先 |
| 武器 | 近接中心。刀剣か格闘装備。銃は持たないことも |
| 色味 | 暗色。目立たない。土や血の汚れが自然 |
| 特徴 | 古傷が多い。装備より肉体に投資 |

#### 裏社会の住人（うらしゃかいのじゅうにん）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | 街に溶け込む私服。コートの下に装備を隠す |
| 装備量 | 隠匿性重視。見えない場所に仕込む |
| 武器 | コンパクト。隠し持てるもの |
| 色味 | 黒・紺・灰。都市迷彩 |
| 特徴 | 一見すると一般人。「装備している」とわからない |

#### 在野研究者（ざいやけんきゅうしゃ）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | 実用的。ポケットが多い。本や端末を持ち歩く |
| 装備量 | 調査機器が中心。戦闘装備は最低限 |
| 武器 | ほぼ持たない。護身用の小型装備のみ |
| 色味 | 地味。図書館にいても違和感がない色 |
| 特徴 | 眼鏡、ルーペ、手帳。知的職業の残り香 |

#### 退魔師（たいまし）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | 和装の要素。ただし祓部古怪班ほど正式ではない |
| 装備量 | 霊的道具中心。数珠、御幣、塩、護符 |
| 武器 | 霊的道具が武器を兼ねる |
| 色味 | 白と暗色の組み合わせ。ただし祓部ほど白くない（くすんでいる） |
| 特徴 | 古怪班との違い：退魔師の白は**黄ばんでいる、古い、手入れが行き届かない** |

#### 路地裏の犬（ろじうらのいぬ）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | ストリートウェア。フード、ジャージ、スニーカー |
| 装備量 | 拾い物・自作が多い。型落ちの寄せ集め |
| 武器 | 手に入ったもの。統一性なし |
| 色味 | 汚れた色。洗濯の余裕がない生活の反映 |
| 特徴 | 若い。痩せている。目だけが鋭い |

#### はぐれ狼（はぐれおおかみ）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | 実戦的。元傭兵の名残があるタクティカルウェア |
| 装備量 | 厳選された少数精鋭の装備。無駄がない |
| 武器 | 使い慣れた一丁。長年の相棒 |
| 色味 | 暗色。傭兵時代の装備色が残る |
| 特徴 | 装備の扱いが丁寧。整備は自分でやる。傭兵との違いは「紋章がないこと」 |

#### 小さな群れ（ちいさなむれ）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | お揃いではないが、どこか共通点がある（同じ色のバンダナ、同じ結び方の紐など） |
| 装備量 | 分担制。一人が武器、一人が道具、一人が食料 |
| 武器 | 共有。交代で使う |
| 色味 | 統一はしていないが、「グループの色」が自然に生まれている |
| 特徴 | リトルクラン（孤児の自治集団）は年齢層が低い。子供用の装備は存在しないので大人用を改造 |

#### 脱走兵（だっそうへい）

| 要素 | 指針 |
|:-----|:-----|
| 服装 | 元の所属の装備を**改変**して使用。紋章を消した跡がある |
| 装備量 | 逃走時に持ち出せた分だけ。欠品が多い |
| 武器 | 元の所属の制式品（改造済み） |
| 色味 | 元の所属色を上塗り。下から元色が覗く |
| 特徴 | 装備の質は高いが、整備されていない。「逃げてきた」感が漂う |

## 8. 生活圏の空間デザイン

### 底澱（そこよど）— 灰嶺市最下層スラム

| 要素 | 描写 |
|:-----|:-----|
| 照明 | 蒼白い魔導街灯が点滅。半分は壊れている |
| 壁面 | 配管むき出し。ケーブルが蔦のように這う。スプレーの落書き |
| 地面 | 水溜り。排水が機能していない。金属の廃材が散乱 |
| 音 | 遠くの機械音。犬の声。時々、怪異の気配 |
| 人 | フードを被った人影。目を合わせない。足早に通り過ぎる |
| 店 | シャッターに「開」と手書き。何を売っているかは入らないとわからない |

### 無所属の「拠点」

拠点と呼べるほどのものはない。あるのは「居場所」。

| 類型 | 拠点の形 |
|:-----|:---------|
| 野良討伐者 | 廃ビルの一室。寝袋と武器だけ |
| 裏社会の住人 | 飲食店の裏部屋。表の店は偽装 |
| 在野研究者 | 本に埋もれたアパート。壁一面が資料 |
| 退魔師 | 荒れた神社の社務所。屋根が半分ない |
| 路地裏の犬 | 路地裏のコンテナ。段ボールと毛布 |
| はぐれ狼 | 車の中。移動しながら生きる |
| 小さな群れ | 地下通路の一画。入口が隠されている |
| 脱走兵 | ネットカフェを転々。同じ場所に留まらない |

## 9. 「描いてはいけない」チェックリスト

イラスト・3D・UIデザインの最終確認用。

### 必須チェック

- [ ] 祓部の紋章（祓幣）が入っていないか
- [ ] 金色 `#d4af37` が使われていないか
- [ ] 《Anonymous》のロゴやランクカードが描かれていないか
- [ ] 装備が全て同一メーカーになっていないか
- [ ] 装備に損傷・使用感が表現されているか
- [ ] 統一された制服になっていないか

### 推奨チェック

- [ ] 装備のメーカーが2社以上混在しているか
- [ ] 企業ロゴが「擦れ・消し跡・上塗り」のいずれかの処理をされているか
- [ ] 修理跡・応急処置の描写があるか
- [ ] 色が統一されすぎていないか（3色以上がバラバラに混在が理想）
- [ ] 民生品（日用品の転用）が1点以上含まれているか
- [ ] 新品のパーツが1つもないか（あっても1つだけ。最近入手した設定）

### 退魔師を描く場合の追加チェック

- [ ] 白衣が古怪班の白衣と区別されているか（無所属＝くすみ・汚れ・不揃い）
- [ ] 祓部紋が入っていないか（退魔師≠祓部。独立した存在）
- [ ] 霊的道具が「古道具」に見えるか（新品の御幣は祓部のもの）

### 脱走兵を描く場合の追加チェック

- [ ] 元の所属の紋章が「消されている」描写があるか
- [ ] 元の装備色が「上塗り」の下から透けているか
- [ ] 装備の整備状態が悪いか（逃亡中は整備できない）

## 10. 付録：色コード・早見表

### 色コード

```css
/* 無所属 UI表示用 */
--unaffiliated: #7a7a8a;  /* 灰：所属なし */

/* 装備に現れる「他者の色」（残骸として） */
--trace-sotetsu:   #3a5a8a;  /* 蒼鉄の痕跡：鋼青 */
--trace-raikin:    #c06020;  /* 雷禽の痕跡：焦橙 */
--trace-karasuha:  #3a3a4a;  /* 鴉羽の痕跡：暗炭 */
--trace-shinkirou: #6a3060;  /* 蜃気楼の痕跡：深紫 */

/* 無所属の「自分の色」（意図せず生まれる色） */
```

# KAI-I//KILL プロダクトアイコン デザイン指示書 v1.0

> Webサイト・アプリ・ストア・SNSで使用するプロダクトアイコンの設計仕様。
> favicon、Apple Touch Icon、OGP、ストアアイコン等の全サイズを網羅する。

---

## 1. コンセプト

### ブランドの核

| 要素 | 内容 |
|:-----|:-----|
| タイトル | 電脳怪異譚 KAI-I//KILL |
| ジャンル | 現代伝奇アクションTRPG |
| 世界観 | 近未来日本・魔法インフラ社会・怪異が実在する |
| キーワード | 怪異 / 討伐 / 電脳 / 祓い / HUD端末 |

### アイコンが伝えるべきもの

> 「暗闇の中の金色の光 — 怪異と対峙する者の視界」

- **暗い画面に金が浮かぶ**。ゲームのUI全体が暗色HUDなので、アイコンもそれに従う
- **一目で「怪異に関わるもの」だとわかる**。日本的な紋様・祓いの記号が入る
- **テキストなし**。小サイズ（16px）でも読める図形のみで構成する
- **正方形の中で完結する**。丸マスク（iOS/Android）にも対応

## 2. モチーフ

### 主モチーフ：「斬り裂かれた怪」

「怪」の漢字を極限まで幾何学化し、中央を斜めに切り裂いた構成。

- **「怪」の構造**: 左の「忄」（りっしんべん）＋ 右の「圣」を直線のみで構成
- **切り裂き**: 中央を左上→右下に走る斜線1本が「怪」を2つに断つ。討伐・祓いの一刀を象徴
- **切り裂きの隙間**: 斜線の両側にわずかな空白（2〜3%のギャップ）。ここから金色の光が漏れる

### 代替モチーフ案：「六角と核」

蜃気楼工廠の歪み六角をベースに、中心に怪異の「核」を配置したデザイン。
（世界観的に「怪異の核を破壊する」がゲームの目的のため）

- **六角形**: 正六角形。ただし完全な正六角ではなく、一辺だけが途切れている（怪異の不完全さ）
- **核**: 中心に二重円 + 縦スリット（瞳孔）
- **金の光**: 六角の途切れた部分から金色が漏れる

### 推奨：主モチーフ（「斬り裂かれた怪」）

理由：
- 「怪異を斬る」ゲームのアクション性が伝わる
- 漢字ベースなので日本的な印象が強い
- 幾何学化すると小サイズでも視認できる
- 「怪」の字はタイトル「KAI-I//KILL」の「KAI」に直結

## 3. 構造と寸法

### 基準サイズ：1024×1024px

すべてのサイズはこの基準から縮小する。

```
┌─────────────────────────────┐
│          余白 12%              │
│   ┌───────────────────┐      │
│   │                     │      │
│   │    忄  ╱  圣        │      │  ← 「怪」の幾何学化
│   │      ╱              │      │
│   │    ╱                │      │  ← 斜めの切り裂き（金の光線）
│   │  ╱                  │      │
│   │                     │      │
│   └───────────────────┘      │
│          余白 12%              │
└─────────────────────────────┘
```

### グリッド構成

```
全体: 1024 × 1024px
セーフエリア: 内側 80%（上下左右に10%ずつ余白）
丸マスク対応: 内接円（直径 1024px）の内側にモチーフを収める
角丸マスク対応: 角丸半径 22.37%（Apple HIG準拠）の内側にモチーフを収める
```

### モチーフの配置

| 要素 | 位置 | サイズ |
|:-----|:-----|:------|
| 「怪」全体 | 中央 | セーフエリアの 75% |
| 切り裂き線 | 左上→右下、45度 | 線幅: セーフエリアの 3% |
| 光の隙間 | 切り裂き線の両側 | ギャップ幅: セーフエリアの 2% |
| 光のグロー | 隙間からのにじみ | ぼかし半径 20px（1024px基準） |

## 6. 小サイズでの簡略化

### 段階的簡略化ルール

| サイズ | 表示内容 | 省略事項 |
|:-------|:---------|:---------|
| 512px以上 | フル表示 | なし |
| 192〜511px | 字形の細部を省略 | 「忄」の点を省略。直線のみに |
| 48〜191px | 字形をさらに簡略 | 「怪」の左右を統合。切り裂き+四角形 |
| 32〜47px | 最小構成 | 四角形 + 斜めの金線のみ |
| 16px | 極小 | 金の斜線が入った暗い四角のみ |

```
512px:  完全な「怪」+ 切り裂き + グロー
 ↓
192px:  簡略化した「怪」+ 切り裂き
 ↓
 48px:  □ に斜めの金線
 ↓
 16px:  ■╱（ほぼ2ピクセルの金線）
```

## 7. 構成要素の描き方

### 「怪」の幾何学化

「怪」= 忄（りっしんべん）+ 圣（つち+又）

```
忄の幾何学化:
  │    ← 縦線（中心の芯）
 ╱     ← 左はらい（45度の斜線）
  ╲    ← 右はらい（45度の斜線）

圣の幾何学化:
 ─┬─   ← 「土」上の横線
  │    ← 「土」の縦線
 ─┴─   ← 「土」下の横線
 ╱ ╲   ← 「又」の交差
```

すべて直線で構成する。曲線は使わない。
線の端は丸めず、ぶつ切り（square cap）にする。

### 切り裂き線

- 角度: 左上→右下、正確に 45度
- 線幅: モチーフ全体幅の 3%
- 色: 金 `#d4af37`
- グロー: `box-shadow: 0 0 20px rgba(212, 175, 55, 0.4)`（1024px基準）
- 隙間: 切り裂き線の両側に 2% の空白。ここが「斬り裂かれた」表現

### 走査線（任意）

アイコン全体に薄い走査線を入れてもよい（サイト全体のHUD感との統一）。

```
repeating-linear-gradient(
  transparent 0px, transparent 2px,
  rgba(0,0,0,0.06) 2px, rgba(0,0,0,0.06) 4px
)
```

ただし 48px 以下では走査線を入れない（潰れるため）。

## 8. 禁止事項

| # | 禁止 | 理由 |
|:--|:-----|:-----|
| 1 | グラデーション背景 | 暗色単色がブランドの基調。グラデは安っぽく見える |
| 2 | 金以外のアクセント色 | 金がブランドの唯一のアクセント。青や赤を入れない |
| 3 | 影（ドロップシャドウ） | フラットな構成。影は使わない。グローのみ許可 |
| 4 | 丸いフォント・手書き風 | 直線・幾何学・モノスペースがブランド言語 |
| 5 | 写実的なイラスト | 抽象・記号・幾何学で構成する |
| 6 | テキストを入れる | 小サイズで読めない。アイコンは図形のみ |
| 7 | 白背景に灰色の字形 | コントラスト不足。白背景では黒字形にする |
| 8 | 角丸を自分で付ける | OS側がマスクする。アイコン自体は正方形で書き出す |

## 9. ファイル配置

Next.js の App Router 規約に従い、以下に配置する。

```
src/app/
├── favicon.ico          ← マルチサイズICO
├── icon.svg             ← SVGファビコン
├── apple-icon.png       ← Apple Touch Icon (180×180)
├── opengraph-image.png  ← OGP画像 (1200×630)
└── manifest.json        ← PWA用（icon-192, icon-512を参照）

public/
├── icon-192.png
├── icon-512.png
└── icon-1024.png        ← マスターファイル
```

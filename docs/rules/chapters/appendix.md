# APPENDIX　クイックリファレンス

## ■ 判定

1. 能力値ランクに応じたd6を振る（D=1個〜A=4個）
2. 1個を達成値、1個を共鳴ダイスとして選ぶ
3. 出目1=ファンブル、出目6=スペシャル（段階修正の影響を受けない）
4. 段階修正を適用（+なら達成値+1、−なら達成値−1）
5. スキル修正を加算（合計上限+4。段階修正とは別枠）
6. 最終達成値≧4で成功

## ■ 共鳴メーター上昇

- 判定の文脈に応じたメーターが上昇
- 通常+1、スペシャル+2、ファンブルは恐怖+2（強制）
- 臨界（10点）で代償発動→0にリセット（浄化のみ恩恵）

## ■ 魔法リスク（怪異誘発判定）

術判定失敗時または大規模魔法時にGMが1d6：
- D=4以上で怪異発生 / C=5以上 / B=6のみ / A以上=発生しない

## ■ 異能リスク

- 異能は魂で判定。ファンブルで制御不能な効果が発動する
- 拡張ルール（EX-5.5）導入時は侵食率が上昇する追加リスクが発生

## ■ 戦闘（核護衛戦）の流れ

```
① ラウンド開始処理（再生・侵食・状態回復）
② イニシアチブ決定（疾ランク順。PC・護衛を混合）
③ ターン処理（メイン×1＋サブ×1。リアクション×1はターン外）
④ ラウンド終了処理（核HP確認・制限ラウンドチェック・共鳴臨界チェック）
```

## ■ スキル（6軸）

- **共通**：全員取得可 / **所属**：自分の所属 / **配属**：自分の配属班・専門・流儀
- **覚醒**：自分の覚醒パターン / **背景**：自動取得（枠消費なし） / **武器技能**：自分の武器型
- スキル枠を消費して取得。必要レベルを満たさなければ取得不可
- パッシブ＝常時発動。メイン/サブ/リアクション＝対応する行動枠を使用

## ■ 段階一覧（13ステップ）

```
D- → D → D+ → C- → C → C+ → B- → B → B+ → A- → A → A+ → S
```

+段階 = 達成値+1 / −段階 = 達成値−1 / ファンブル・スペシャルは出目で判定

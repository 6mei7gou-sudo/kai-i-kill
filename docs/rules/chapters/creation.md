# CHAPTER 9　キャラクター作成

## 9-1　作成の流れ

```
① 全能力値をランクDからスタート（7能力値すべてD）
② 背景を1つ選ぶ（2能力値がランクCへ昇格＋背景スキル自動取得）
③ 所属を選ぶ（祓部・傭兵・無所属。CHAPTER 10参照）
④ 配属を選ぶ（1能力値がランクBへ昇格＋配属スキル解放）
   └ 祓部→配属班 / 傭兵→専門 / 無所属→流儀
⑤ 覚醒パターンを選ぶ（先天型・ショック型・実験型・接触型）
⑥ ギフトを初期ギフトの中から1つ選ぶ
⑦ 武器型を選ぶ（斬撃・打撃・射撃・魔導・体術）
⑧ スキルを2つ選択（解放された軸＋共通から）
⑨ 段階調整：任意の能力値2つに+段階を付与する（同じ能力値に2回は不可）
⑩ 装備をCP予算（Lv1: 10CP）の範囲内で選択
⑪ 信念を設定（最大5点からスタート）
⑫ 怪異予兆カードをGMから受け取る
```

### 段階調整について

キャラクター作成の⑨で、任意の能力値2つに**+（プラス）段階**を付与できる。これにより初期キャラクターに個性が生まれる。

**例：** 背景「鋼の肉体」（体C・疾C）→ 所属「傭兵」→ 配属「突撃型」（体→B）→ 段階調整で体と察に+ → 体B+・疾C・察D+。体は「突撃屋の中でも最も硬い男」、察は「戦場で磨いた嗅覚」を表現。

段階調整はD〜Aのランクにのみ適用できる。初期段階は−にはならない（−段階は負傷や呪い等で後天的に発生する）。

| **魔道資格者** | 術・識 | 選択した魔法言語の+1修正が2状況に拡張。怪異誘発判定の確率が1ランク改善 |

## 9-3　配属（所属に連動）

所属に応じて**配属班**（祓部）・**専門**（傭兵）・**流儀**（無所属）を1つ選ぶ。配属は能力値のB昇格と専用スキルの解放を決定する。スキルの詳細はCHAPTER 5-4〜5-6を参照。

### 祓部の配属班

| 配属班 | B昇格 | 特色 |
|---|---|---|
| **古怪班** | 識→B | 古い怪異の調査・解明特化。伝承・禁足地の知識 |
| **新怪班** | 察→B | 現代型怪異の追跡・分析。SNS・デジタルメディア |
| **封印班** | 魂→B | 禁足地の管理と特級怪異の封印。浄化の専門家 |
| **機動班** | 体→B | 前線投入の実働部隊。直轄即応隊・広域機動班 |

### 傭兵の専門

| 専門 | B昇格 | 特色 |
|---|---|---|
| **突撃型** | 体→B | 火力と耐久の前衛。傭兵の花形 |
| **偵察型** | 察→B | 情報収集と戦場分析。目と耳の専門家 |
| **技術型** | 術→B | 装備改造と魔法技術。後方支援 |
| **護衛型** | 判→B | 要人護衛と脅威評価。交渉と戦術判断の専門家 |

### 無所属の流儀

| 流儀 | B昇格 | 特色 |
|---|---|---|
| **野良討伐者** | 体→B | 組織に頼らず腕一本で戦う。生存特化 |
| **裏社会の住人** | 判→B | 情報網と人脈で勝負。交渉と策略 |
| **在野研究者** | 識→B | 独自に怪異を研究する学者肌 |
| **退魔師** | 魂→B | 独学で祓いの術を身につけた一匹狼 |

## 9-3.5　武器型

武器型を1つ選ぶ。所属・配属・覚醒パターンとは**完全に独立**しており、どの組み合わせでも好きな武器型を選べる。武器技能の詳細はCHAPTER 5-9を参照。ベース武器カタログは weapon_custom_data CHAPTER 5 を参照。

| 武器型 | 概要 | 対応ベース武器 |
|---|---|---|
| **斬撃型** | 切れ味と手数 | 剣・小刀・太刀・大剣・薙刀・鎖鎌 |
| **打撃型** | 一撃の破壊力 | 斧・両手斧・ハルバード・メイス・槍 |
| **射撃型** | 距離と精度 | 弓・銃・ボウガン・ライフル・ショットガン・投擲武器 |
| **魔導型** | 魔法との連携 | 魔導杖・魔導書・符・結界具 |
| **体術型** | 素手の技巧 | ナックル |

## 9-4　覚醒パターン

キャラクターが討伐者になった経緯。動機と背景に直結する。

| パターン | 概要 | 機械的特徴 |
|---|---|---|
| **先天覚醒型** | 生まれつき素養を持ち訓練で開花 | 術または魂のランクがCでスタート（背景の昇格とは別） |
| **ショック覚醒型** | 怪異に関わる強烈な体験が引き金 | 恨みや喪失に対する判定に+1。初期信念ポイント+1 |
| **実験覚醒型** | 人体実験で強制覚醒 | 異能ランクに+1。察判定+1（怪異の気配への過敏さ） |
| **接触覚醒型** | 怪異の核や特殊素材への長期接触で覚醒 | 察判定に常時+1（怪異の気配への鋭敏さ） |

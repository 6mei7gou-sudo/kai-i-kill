# CHAPTER 8　異能

## 8-1　異能とは

異能は「内側から生まれる力」だ。怪異と同じ発生原理を持ち、魔法とは根本的に異なる。

| 項目 | 魔法 | 異能 |
|---|---|---|
| 原理 | 外部（世界への介入） | 内部（自身の変質） |
| 再現性 | 高い | 低い |
| 習得方法 | 訓練と素養 | 体験と執着 |
| リスク | 怪異を生む | 使用者が変質する |

## 8-2　異能使用判定

異能の発動は**魂**による判定を行う。

| 結果 | 効果 |
|---|---|
| スペシャル（6） | 効果が最大出力で発揮。渇望メーター+2 |
| 成功（4〜5） | 効果発揮。渇望メーター+1 |
| 失敗（2〜3） | 効果なし。渇望メーター+1 |
| ファンブル（1） | 制御不能な効果発動（GM決定）。渇望メーター+2・恐怖メーター+2 |

> **拡張ルール：** 追加データブック《禁域解放》EX-5.5を導入すると、異能使用ごとに侵食率が上昇する追加リスクが発生する。

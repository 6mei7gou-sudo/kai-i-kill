## 序章　この本について

### 0-1　どんなゲームか

舞台は近未来の架空日本。魔法は電気やガスと同じインフラとして社会に組み込まれ、その裏側では噂が質量を持ち、現実のバグとして侵食する**怪異**が日常的に発生している。

あなたは**討伐者**だ。怪異を調査し、核とルールを暴き、討伐する。

> **このゲームは『怪異を調べ、ルールと核を暴き、撃つ。ただし強く行動するほど感情が怪異に共鳴し、共鳴は力であり、同時に代償である』という体験を提供するTRPGだ。**

この一文に貢献しないルールは、本書には入っていない。

### 0-2　面白さの三層

| 層 | 体験の核心 | ルール上の担保 |
|---|---|---|
| **パズルとしての討伐** | 小さな怪異は力で押し潰せる。だが二級以上の怪異はルールと核を解明しなければ倒せない。知識が命を救う | 解明鍵が防壁層と核の防御に直結する（第4章・第5章） |
| **感情のジレンマとしての判定** | 強く成功するほど感情が共鳴する。共鳴は力だが、偏ると代償が来る | 共鳴量＝選んだ出目−3（第2章・第3章） |
| **問いとしての世界観** | 怪異と神の違いは恐れか信仰か。討伐者たちは正しいことをしているのか | 臨界の代償、信念の重圧（第3章・第11章） |

### 0-3　必要なもの

- 6面ダイス（d6）を **4個以上**。プレイヤーごとに用意すると進行が速い
- キャラクターシート（巻末）
- 共鳴メーター記録欄（キャラクターシートに含む。6本×10マス）
- 筆記具、消しゴム
- GM（ゲームマスター）1人とプレイヤー（PL）2〜4人。想定は **GM1＋PL3〜4、1セッション3〜4時間**

### 0-4　用語の約束

| 用語 | 意味 |
|---|---|
| **PC** | プレイヤーが演じる討伐者 |
| **NPC** | GMが演じる登場人物 |
| **判定** | 行為の成否を決めるダイスロール（第2章） |
| **達成値** | 判定で選んだダイスの出目に修正を加えた値 |
| **共鳴** | 判定のたびに感情メーターへ蓄積する値（第3章） |

# PART I　世界

## 第1章　世界観

> *「噂が臨界点を超えた時、それは現実のバグになる。」*
> *「知識が命を救う。無知が人を殺す。」*

### 1-1　怪異のメカニズム

怪異とは、集合的な噂・言説・信念が臨界点を超えた時に現実へと侵食する**バグ**だ。魔法を「チートコード」と呼ぶのに対し、怪異は「バグ」と呼ばれる。意図的な介入と、意図せぬ誤作動の違いだ。

すべての怪異は**核**（コア）と**ルール**を持つ。

| 概念 | 内容 |
|---|---|
| **核（コア）** | 怪異の存在の中心。物・場所・記録媒体に宿る。稀に人間に宿る。核を破壊すれば怪異は消滅する |
| **ルール** | 怪異が人を害する条件と行動原則。ルールを破るほど怪異に捕捉される。逆に、ルールを知れば避けられる |

怪異は噂から生まれる。だから噂が広まるほど強くなり、噂が消えれば弱る。討伐者の仕事は噂を消すことではない——それは現実的に不可能だ——核を壊し、今そこにいる怪異を消すことだ。

### 1-2　怪異の等級と種別

怪異は**存在強度等級**と**脅威度種別**の二軸で表記される。「三級・甲種」のように読む。

#### 存在強度等級

| 等級 | 位置づけ | 基準 | 討伐の前提 |
|---|---|---|---|
| **特級** | 災害 | 現状の手段では消滅が極めて困難。封印・管理が限界 | 討伐不可。封印を目指す |
| **一級** | 大ボス | 信念密度が非常に高い。長い歴史を持つ強力な怪異 | 解明必須 |
| **二級** | ボス | 記録のある古い怪異の大半 | 解明必須 |
| **三級** | 中ボス | 拡散が進んだ新しい怪異など。力押しも不可能ではない | 解明推奨 |
| **四級** | 雑魚 | 発生したばかりの新しい怪異 | 解明不要 |
| **五級** | 雑魚 | 魔法事故由来の微小怪異。自然消滅することも多い | 解明不要 |

#### 脅威度種別

| 種別 | 基準 |
|---|---|
| **甲種** | 無差別に人を害する。接触した全員が標的 |
| **乙種** | ルールを破った者など、条件付きで害する |
| **丙種** | 刺激しなければ安全。放置が最善の場合がある |
| **丁種** | 人を害さない。共存可能、または信仰対象に近い |

存在強度と脅威度は一致しない。強いが安全な怪異（一級丁種）も、弱いが危険な怪異（五級甲種）も存在する。

#### 永続性

| 型 | 内容 |
|---|---|
| **一時型** | 核を壊せば消える標準的な怪異。噂が変質して派生体が後日出ることはある |
| **循環型** | 社会に根を張った都市伝説型。核を壊しても噂が生きている限り再出現する。討伐は根絶ではなく**制圧**だ |
| **定着型** | 土地そのものに根を張った怪異。禁足地に指定され、封鎖・管理される |

#### 古い怪異と新しい怪異

**古い怪異**は伝承・文献・口承に対処法の痕跡がある。強いが、知識があれば糸口がある。神社・古文書・民俗学者が頼りになる。

**新しい怪異**はSNS・都市伝説・ネットロアから生まれる。強さは低めだが、**データベースに記録がなく、初見殺し**が最大のリスクだ。

#### 改造個体と別個体

怪異は外部からの干渉でルールが変質することがある。

- **改造個体**：ルール変質が50%未満。元の知識がある程度通用するが、決定的にルールが食い違う瞬間がある
- **別個体**：ルール変質が50%以上。新しい核と新しいルールを持つ、完全に別の怪異。元の知識はほぼ役に立たない

変質割合を現場で判定する確立された手段はない。誤判定は討伐失敗に直結する。

### 1-3　能力体系——魔法と異能

| 種別 | 概要 | リスク |
|---|---|---|
| **魔法（チートコード）** | 世界のソースコードへの直接介入。素養と訓練で習得する。インフラとして資格制度がある | 使う規模に比例して**怪異を生む** |
| **異能（アプリケーション）** | 怪異と同じ発生原理の延長線上にある力。体験・執着・信念から発現する | 使用者が**変質する**。本書では渇望メーターで表す |

魔法で怪異を倒すことと、魔法で怪異を生むことは表裏一体だ。異能は自分自身を怪異に近づける。どちらも、討伐者が「何かを失っていく」過程を刻む。

### 1-4　討伐免許制度

怪異の討伐は免許制だ。魔導省が管轄する**討伐免許**を取得しなければ、合法的に怪異を討伐することはできない。

| 項目 | 内容 |
|---|---|
| **管轄** | 魔導省（祓部が実務を担当） |
| **取得条件** | 素養検査合格＋初期講習の修了 |
| **定期講習** | 年1回の更新講習が義務。怪異の最新動向・装備の安全基準・法改正の共有が行われる |
| **主な依頼内容** | 五級怪異の討伐が大半。日常的に湧く雑魚の駆除が討伐者の基本業務だ |
| **高等級の依頼** | 三級以上も祓部の専管ではない。祓部の管理案件として傭兵への委託や合同作戦になるものもあれば、企業や個人から民間の討伐者に直接発注される案件もある |

免許を持たない者が怪異を討伐すれば、それ自体が犯罪として問われる。無所属の討伐者の多くは、この線の上を歩いている。

### 1-5　三組織

討伐者は所属によって「使えるリソース」と「縛り」が決まる。

#### 祓部（はらえべ）

魔導省内部の公的討伐機関。神職系の称号を持つ専門家集団で、データベースと情報に優位を持つ。

- **強み**：公的データベース照会（識の調査判定+2、1セッション3回）／援軍要請（1セッション1回、NPC祓士の支援）
- **制約**：任務命令への服従が義務。独断行動は処分対象。装備と行動に法的・組織的な制限がかかる。組織内の方針の違いが任務に影響することがある
- **配属班**：古怪班（古い怪異の調査）／新怪班（現代型怪異の追跡）／封印班（禁足地管理と封印）／機動班（前線の実働部隊）

#### 傭兵

企業または個人として依頼を受けて動く討伐者。傭兵ネットワーク**《Anonymous》**を通じて仕事を得る。依頼はレーティング制で、実績を積めば高難度・高額の案件と指名依頼が解禁される。

- **強み**：装備グレード（作成時に装備を1ランク上から選べる）／コネクション（企業・裏社会の縁による情報収集判定+2、1セッション3回）／二つ名（その分野の判定に常時+1）
- **制約**：収益がなければ活動継続が困難。バック企業の方針に縛られる。法的に保護される範囲が限られる
- **専門**：突撃型（火力と耐久）／偵察型（情報と分析）／技術型（装備改造と魔法技術）／護衛型（要人護衛と戦術判断）

#### 無所属

祓部にも《Anonymous》にも属さない者たち。装備店の主人、企業の用心棒、スラムの生存者。子供たちの寄り合い**リトルクラン**もここに含まれる。

- **強み**：生存者の勘（察判定に常時+1）／裏のルート（1セッション1回、曰く付き装備・違法情報にアクセス）／改造個体センサー（「何かがおかしい」と感じた時、GMにヒントを1つ要求。1セッション1回）
- **制約**：法的保護がない。祓部・傭兵のどちらからも警戒される。安定した補給・整備のルートがない。定期講習を受けていないため最新の怪異情報に疎い
- **流儀**：野良討伐者（腕一本の生存者）／裏社会の住人（情報網と人脈）／在野研究者（独学の学者肌）／退魔師（独学の祓い手）

### 1-6　魔導具産業と企業

魔導具産業は**国家系**（安全・保守・安定）と**独立系**（高性能・高リスク）の二極構造を持つ。すべての企業が怪異発生リスクと隣り合わせで製品を作っている。

| 企業 | 性格 | 討伐者との接点 |
|---|---|---|
| **蒼鉄機工** | 国家系。安全第一。官製品として法的に保護される | 祓部の標準装備。拒絶反応が起きにくい |
| **雷禽重工** | 独立系。高出力で尖った製品 | 傭兵市場の主流。強いが共鳴を煽る |
| **銀鎚精機** | 個人受注の特注品。納期は半年〜1年 | 一点物。武器修正が1段高い |
| **鴉羽技研** | 技術研究と施術。表に出ない仕事も請ける | 出所を問わない装備と改造 |
| **朱鷺崎財閥・技術部門** | 財閥の技術部門。内実は外から見えない | 特殊な案件で名前が出る |

装備のメーカー別補正は第10章に示す。

# PART II　ルール

## 第2章　判定

> *「ダイスを振れ。そして、どの目を使うか決めろ。全部使う必要はない。」*

### 2-1　能力値とランク

キャラクターは7つの**能力値**を持つ。各能力値は**ランク**（D〜S）で表され、ランクが判定で振るダイスの数を決める。

| 能力値 | 読み | 主な用途 |
|---|---|---|
| **体** | たい | 格闘・突破・耐久・援護 |
| **疾** | はや | 先手・回避・追跡・射撃の命中 |
| **識** | しき | 調査・知識・文献・解明 |
| **判** | はん | 解明宣言・看破・戦術・交渉 |
| **察** | さつ | 怪異感知・観察・証言聴取 |
| **術** | じゅつ | 魔法行使・魔導具操作 |
| **魂** | こん | 異能制御・信念維持・精神防御・浄化 |
<!-- /table -->

<!-- table:ranks -->
| ランク | ダイス | 位置づけ |
|---|---|---|
| **D** | 1d6 | 初期値。出目がそのまま結果になる |
| **C** | 2d6 | 一人前。2つ振って選べる |
| **B** | 3d6 | 熟練。配属特化の領域 |
| **A** | 4d6 | 達人。成長の先にある |
| **S** | 4d6＋固有特典 | 規格外。物語の果てに辿り着く者だけの領域。通常の成長では到達できない |

### 2-2　判定の手順

1. GMが**能力値**と**目標値**を宣言する
2. ランクに応じた個数の d6 を振る（専心・負傷があればダイス数を±1個する。2-5参照）
3. 出た目から **1個を選ぶ**。その出目が**達成値**の基礎になる
4. 修正を加える（合計 +3 まで。2-6参照）
5. 達成値が目標値以上なら**成功**
6. **選んだ出目 − 3**（最低0）を、行為に対応する**共鳴メーター**に加算する（第3章）

> **例：** 識Bの討伐者が古文書を読み解く（目標値4）。3d6を振って 5・3・2。5を選べば達成値5で成功、哀愁メーター+2。もし出目が 6・4・1 なら、4を選んで成功・哀愁+1で済ませるか、6を選んでスペシャルを取りに行き哀愁+3を払うかを選べる。

ダイスの個数が多いほど「通りやすい」だけでなく、「必要最低限の目を選んで**安く済ませられる**」。これがランクの価値だ。

| ランク | 目標値4の成功率 | 成功時の平均共鳴※ |
|---|---|---|
| D | 50% | +2.00 |
| C | 75% | +1.85 |
| B | 87.5% | +1.71 |
| A | 93.75% | +1.59 |

※成功する中で最も低い目を選ぶ最節約プレイをした場合の期待値。

**選択が本当に発生するのは、達成値がダメージに直結する戦闘中だ。** 出目4を選べばダメージ4・怒り+1、出目6を選べばダメージ6＋スペシャル特典・怒り+3。戦闘外の判定は「成功する最低の目を選ぶ」でよく、悩む必要はない。判定のたびに考え込ませない設計になっている。

### 2-3　目標値

| 難易度 | 目標値 | 例 |
|---|---|---|
| **通常** | 4 | 大半の行為。戦闘の攻撃 |
| **困難** | 5 | 不利な状況。二級以上の怪異への解明 |
| **至難** | 6 | 常識の外側。スペシャルでしか通らない |

GMは迷ったら目標値4を使う。目標値を上げるのは「この状況は明らかに難しい」と卓の全員が納得する時だけでよい。

### 2-4　スペシャルとファンブル

| 結果 | 条件 | 効果 |
|---|---|---|
| **スペシャル** | 選んだ出目が **6** | 自動成功。行動ごとの追加効果（攻撃なら防御力無視、など）。共鳴+3 |
| **ファンブル** | 振った目が**すべて3以下**で、かつ **1 が1個以上**含まれる | 自動失敗。GMが状況を悪化させる（2-7）。恐怖メーター+2 |

ファンブル率は D=16.7%／C=13.9%／B=8.8%／A=5.0%。高ランクでも消滅しない。「全部3以下で、1が混じっていたらファンブル」と覚えればよい。

> **例：** 体Cで2d6を振って 3・1 → ファンブル。2・3 → ただの失敗。1・5 → 5を選んで成功（1は無視してよい）。

### 2-5　専心と負傷

| 状態 | 効果 |
|---|---|
| **専心（FOCUS）** | その能力値の判定でダイスを **1個追加**して振る |
| **負傷（WOUND）** | その能力値の判定でダイスを **1個減らす**（最低1個） |

専心はキャラクター作成時に **2つ**選び、成長で増える（第11章）。同じ能力値に専心を2つ重ねることはできない。負傷は重傷時などにGMが付与し、ダウンタイムの休息で解除する。専心と負傷が同じ能力値に重なった場合は打ち消し合う。

> **例：** 体B（3d6）に専心 → 4d6。同じキャラが腕に負傷を受ければ 3d6 に戻る。

### 2-6　修正

| 種類 | 上限 |
|---|---|
| スタイルの技・装備・ギフト・所属特典による加算 | 合計 **+3** |
| 状況修正（GM判断） | ±1〜±2。上記とは別枠 |

修正は「選んだ出目」に加える。**修正はスペシャル・ファンブルの判定には影響しない**（出目そのもので決まる）。達成値はダメージにも使われるため、上限を厳しく取ってある。

### 2-7　失敗の扱いと「押し通し」

判定に失敗しても、物語は止まらない。GMは失敗を「進行停止」ではなく**状況の悪化**として処理する——時間を失う、手がかりが汚染される、怪異に気づかれる、負傷する。

さらにPLには**押し通し**（PUSH）という選択肢がある。

> **押し通し：** 失敗した判定について、対応する共鳴メーターを **+3** 支払うことで、**達成値4の成功**に変えられる。

- 1回の判定につき1度だけ
- ファンブルには使えない
- 宣言は出目を見た後でよい
- 押し通しで得た成功はスペシャルにはならない

失敗は「感情を燃やして押し通すか、状況の悪化を受け入れるか」の選択になる。調査フェーズの行き止まりはこれで発生しない。

> **例：** 察Dで気配を探る。出目2で失敗。ここで見落とすと怪異のルールを踏む。PLは「押し通す」と宣言し、恐怖メーターを+3して達成値4の成功にする。怪異には気づけたが、恐怖は7に達し、第三段階の覚醒ギフトが解放されると同時に臨界が目前になった。

### 2-8　対抗判定と協力

- **対抗判定**：PC同士、あるいはPCとNPCが競う時は、双方が判定し達成値の高い方が勝つ。同値ならランクの高い方、それも同じなら仕掛けた側が勝つ
- **協力**：同じ行為に複数のPCが取り組む時、代表1人が判定し、協力者は各1人につき代表の判定に +1 を与える（修正上限に含む）。協力者は共鳴を受けない

## 第3章　共鳴記録

> *「怪異と戦い続ける討伐者の体は、少しずつ怪異の波長に共鳴していく。それは能力として現れることもあるし、人間としての何かを削ることもある。」*

### 3-1　設計思想

《共鳴記録》は、討伐者が判定のたびに刻む感情の蓄積を記録するシステムだ。共鳴が深まれば**ギフト**が解放されるが、臨界まで達すると**代償**が訪れる。

共鳴は隠さない。全員のメーターは卓に公開する。仲間の怒りが9に達しているのを見て、誰がその隣に立つかを決めるのもこのゲームだ。

### 3-2　6つのメーター

各メーターの最大値は **10点**。**どのメーターが上がるかは「何をしたか」で一意に決まる。**

<!-- table:resonance-meters -->
| 行為 | メーター | 色 | 臨界（10点）の代償 |
|---|---|---|---|
| 攻撃・破壊 | **怒り（RAGE）** | 赤橙 | 次の1ラウンド、最も近い敵への最大火力の攻撃しか選べない。出目は最大のものを選ばなければならない |
| 回避・防御・逃走・耐える | **恐怖（FEAR）** | 暗赤 | 次の【魂】判定が自動ファンブルになる |
| 調査・解明・読み解く | **哀愁（SORROW）** | 青 | 次のシーンの調査判定はすべてダイス−1個。信念ポイント−1 |
| 先手・急ぐ・追う | **焦燥（HASTE）** | 橙 | 次の討伐フェーズで、行動宣言を怪異の手番より先に公開する（奇襲・待ち伏せ不可） |
| 魔法・異能・特殊素材 | **渇望（THIRST）** | 紫 | 次の魔法／異能のコストと共鳴が倍になる |
| 浄化・封印・支援 | **浄化（PURGE）** | 白緑 | 代償なし。大浄化が発動する（3-5） |
<!-- /table -->

行為が複数の欄に該当する時は、PLが1つ選ぶ。GMが「この判定は〇〇」と先に宣言してもよい。

### 3-3　上昇量

<!-- table:resonance-gain -->
| タイミング | 上昇 |
|---|---|
| 判定に成功した | 選んだ出目 − 3（+1〜+3） |
| スペシャル | +3 |
| 判定に失敗した | 0 |
| ファンブル | 恐怖 +2 |
| 押し通しを使った | 対応メーター +3 |
| ダメージを受けた | 恐怖 +1 |
| 仲間が気絶した | 哀愁 +1 または 怒り +1（PL選択） |
| 討伐フェーズで制限ラウンド残り1 | 焦燥 +1（全PC） |
| 技・装備・ギフトの指定 | 記載の通り |
<!-- /table -->

想定では、1セッション25判定前後（平均+1.8）に被弾や押し通しを加えて合計 +45〜60。スタイルと役割に応じて2〜3のメーターに偏るため、各PCが**1セッションに1〜2回、臨界を踏む**。臨界は事故ではなく山場として設計されている。

### 3-4　覚醒段階と臨界

<!-- table:resonance-stages -->
| 蓄積 | 段階 | 解放されるもの |
|---|---|---|
| 1〜3 | **第一段階** | 初級覚醒ギフト（第8章） |
| 4〜6 | **第二段階** | 中級覚醒ギフト |
| 7〜9 | **第三段階** | 上級覚醒ギフト |
| **10** | **臨界（CRITICAL）** | 代償が発動し、そのメーターは 0 に戻る |
<!-- /table -->

覚醒ギフトは、メーターがその段階以上にある間いつでも使える。つまり**臨界に近いほど強い**。臨界まで押し切って代償を受けるか、浄化して段階を下げるか——その選択が《共鳴記録》の核だ。

### 3-5　大浄化

浄化メーターが臨界に達した時は、代償の代わりに**大浄化**が発動する。

- 自分の**すべてのメーターを −3**（浄化は0に）
- 討伐フェーズ中なら、怪異の次の手番を**スキップ**させる

浄化に偏ったキャラクターは、パーティの安全弁になる。

### 3-6　共鳴を下げる方法

| 方法 | 効果 |
|---|---|
| 基本行動【浄化】（第5章） | 自分か味方1人のメーター1種を −2 |
| スタイル「封印」の技（第7章） | −3 など |
| ダウンタイムの休息（第11章） | 全メーターを半分（切り捨て）に |
| シナリオの終了 | 全メーターを半分（切り捨て）に。臨界を踏んだメーターは0のまま |

## 第4章　セッションの流れ

### 4-1　全体の構造

```
[1] 導入 ──── 依頼・怪異の発生報告。怪異予兆カードを各PCに1枚配る（非公開）
[2] 調査フェーズ ── 解明鍵4つを集める
[3] 解明完了宣言 ── 【判】判定。成功で討伐フェーズの条件が緩和される
[4] 討伐フェーズ ── 核防壁戦（第5章）
[5] 事後 ────── 報酬・レベルアップ・ダウンタイム（第11章）
```

すべての段階を踏む必要があるのは**二級以上**の怪異だ。五級・四級は見つけ次第叩ける。三級は力押しも可能だが、調べてから挑んだ方が確実に生き残れる。

### 4-2　調査フェーズ

GMは怪異の噂・被害・現場を提示し、PCは手がかりを追う。調査手段は自由だ。

- 被害者・目撃者への聞き込み（察・判）
- 現場の物的証拠の収集（察）
- 公的機関のデータベース照会（識。祓部は+2）
- 民俗学文献・古文書の調査（識）
- SNSや都市伝説サイトの追跡（識・察）
- 現地での直接観察（察。ルールを踏む危険がある）

調査フェーズは**シーン制**で進める。GMが場面を提示し、PCは1シーンに1回ずつ主要な判定を行う。目安は1シナリオ 4〜8シーン。

### 4-3　解明鍵

調査で集めるものは**4つの解明鍵**だ。

| 鍵 | 内容 | 主な能力値 |
|---|---|---|
| **① 発生源** | どんな噂・信念から生まれたか。古い怪異か新しい怪異か | 識 |
| **② ルール** | 何を条件に人を害するか。誰が狙われるか | 察・判 |
| **③ 核の所在** | 核がどこに宿っているか | 察・識 |
| **④ 弱点** | 何が核を傷つけられるか。例外条件 | 判 |

鍵は判定の成功で1つずつ得る。順番は問わない。ただし④は①〜③のどれかを得た後でなければ挑めない。

**鍵を1つ得るごとに：**

- 討伐フェーズで、防壁層の特性が1つ公開される（GMが選ぶ）
- その怪異へのダメージが全PC **+1**（累積。最大+4）

### 4-4　解明完了宣言

4鍵すべてを得た状態で、PCの誰かが**解明完了宣言**を行う。【判】判定、目標値4（二級以上は5）。

**成功すると討伐フェーズで：**

- 核の防御力が **0** になる
- 防壁層が **1つ即座に剥離**する
- 宣言者の浄化メーター +2

失敗しても宣言は再挑戦できる（押し通し可）。時間の余裕がない時は、鍵3つで強行してもよい——ただし核の防御力は変わらず、層も剥がれない。

> **解明は「戦闘を短くする投資」だ。** 調べた分だけ討伐フェーズが軽くなる。逆に、調べずに突っ込めば戦闘は長引き、共鳴は溜まり、臨界が来る。

### 4-5　改造個体・別個体の罠

文献との齟齬、被害パターンの不一致、核の所在の混乱、目撃証言の分裂——これらは「何かがおかしい」サインだ。

- **改造個体**：解明中のある一点でルールが決定的に食い違う。GMは鍵②か④の判定を**困難**（目標値5）にしてよい
- **別個体**：解明の途中で、全く別の核とルールを持つと判明する。それまでの鍵のうち、GMが指定した1〜2個が無効になる

無所属の「改造個体センサー」で、改造個体か別個体かのヒントを1回GMに要求できる。

### 4-6　怪異予兆カード

GMはセッション開始前に各PCへ**怪異予兆カード**を1枚配る。本人のみ閲覧できる。

カードには次の3つが書かれている。

- **公開条件**：いつカードを公開するか（例「解明鍵②を得た時」「哀愁メーターが5以上になった時」）
- **公開効果**：公開すると何が起きるか（例「解明鍵を1つ追加で得る」「浄化メーター+2」「防壁層1つが即座に剥離」）
- **秘密情報**：そのPCだけが知る設定（過去の因縁・怪異との接触歴・NPCとの関係）

予兆カードは物語に「そのPCだけの角度」を与える装置だ。GMは1シナリオに最低1枚は、討伐フェーズに直結する効果を仕込む。

### 4-7　シナリオの終了

- 討伐成功／封印成功／撤退のいずれかでシナリオは終わる
- 全PCのメーターを半分（切り捨て）にする。臨界を踏んだメーターは0のまま
- レベルアップとダウンタイム（第11章）

## 第5章　討伐——核防壁戦

> *「護衛を剥がせ。核が見えたら、撃て。」*

### 5-1　構造

二級以上の怪異の核は剥き出しではない。核は**防壁層**に守られている。層が健在な間、核は攻撃できない——層を剥がして初めて、核への道が開く。

```
        【核（コア）】 核HP／核防御力
             ↑ 守る
      【防壁層】 層HP（共有）・層特性1つ      ← 1〜3層。上の層から剥がす
             ↕
        【討伐者チーム】
```

**護衛は個体として管理しない。** 層は1つの共有HP（**層HP**）・**層防御力**・1つの**層特性**を持つ塊だ。層防御力は等級で決まる（5-7）。層HPが0になると層が**剥離**し、次の層（または核）が露出する。余剰ダメージは次の層へ貫通する。

演出上は、層に「足音の群れ」「拡散する分身」「車掌」などの名前と姿を与える。数字は1つでも、卓の上では何体いてもよい。

### 5-2　ラウンド進行

1. **ラウンド開始**——層特性の開始時効果（再生など）を処理する
2. **PCの手番**——【疾】ランクの高い順（同ランクならPLが相談して決める）。各PCは **メイン行動1・サブ行動1**
3. **怪異の手番**——ラウンドに1回、まとめて処理する（5-4）
4. **ラウンド終了**——制限ラウンドを進め、共鳴の臨界をチェックする

PC4人卓なら、1ラウンド＝5回の処理で済む。

### 5-3　基本行動

スタイルの技を持っていなくても、すべての討伐者は次の行動ができる。

#### メイン行動

| 行動 | 能力値 | 効果 | 共鳴 |
|---|---|---|---|
| **攻撃** | 体／疾 | ダメージ ＝ 達成値 ＋ 武器修正 − 防御力（最低1）。スペシャルなら防御力を無視しダメージ+1 | 怒り |
| **魔法行使** | 術 | 魔法の効果（第9章）。ダメージ魔法は 達成値 ＋ 術式修正 − 防御力 | 渇望 |
| **解明** | 識／察 | 戦闘中に解明鍵を1つ進める（目標値5） | 哀愁 |
| **干渉** | 判 | 層特性を1つ、次のラウンド終了まで無効化する | 哀愁 |
| **浄化** | 魂 | 自分か味方1人の共鳴メーター1種を −2 | 浄化 |
| **異能発動** | 魂 | 異能を使う（第9章） | 渇望 |

#### サブ行動

| 行動 | 効果 |
|---|---|
| **移動** | 位置・射程の調整（演出） |
| **アイテム** | 回復薬などの使用 |
| **観測** | 最上層の層HPと核HPの残量を知る（判定不要） |
| **構え** | 怪異の手番での回避判定に、ダイス +1個 |
| **庇う** | 怪異の手番で、味方1人が受けるダメージを代わりに受ける（自分の回避判定は行えない） |

### 5-4　怪異の手番

怪異は**脅威度**を持つ。ラウンドに1回、GMは層特性に応じて次の行動から1つを選ぶ。既定は【襲撃】。

| 行動 | 効果 |
|---|---|
| **襲撃** | 全PCに **脅威度** のダメージ。各PCは【疾】判定（目標値4）を行い、成功で**半減**（切り上げ）、スペシャルで**無効**。受けるダメージからは**防御修正**を引く（5-5） |
| **侵蝕** | 全PCの、GMが指定するメーター +2 |
| **再生** | 最上層の層HPを 脅威度 だけ回復する（最大値まで） |
| **貫通** | 最もHPの低いPC1人に **脅威度×2** のダメージ。回避判定可。防御修正を引く（5-5） |

回避判定の共鳴は**恐怖**だ。避けるたびに怖くなる。

> **例：** 三級怪異（脅威度6）の襲撃。疾Cのアカリは2d6で 4・2 → 4を選んで成功、ダメージ3（半減）、恐怖+1。疾Dのテツは1d6で 2 → 失敗、ダメージ6、被弾で恐怖+1。

### 5-5　ダメージと状態

#### PCのHP

```
最大HP ＝ 10 ＋ 体ランクボーナス ＋ レベルHPボーナス ＋ 背景・装備ボーナス
```

| 体ランク | D | C | B | A |
|---|---|---|---|---|
| HPボーナス | +0 | +2 | +4 | +6 |

| HP | 状態 | 効果 |
|---|---|---|
| 最大の半分以下 | **負傷** | 演出。ペナルティなし |
| 3以下 | **重傷** | GMは能力値1つに**負傷**（ダイス−1個）を付与できる |
| 0 | **気絶** | 行動不能。攻撃対象にならない。味方の【体】判定成功（サブ行動「庇う」の代わりに行う）で1HPで復帰 |

#### 受けるダメージ

```
受けるダメージ ＝ 脅威度（貫通は×2） − 防御修正 → 回避成功なら半分（切り上げ）
```

- **防御修正**は装備分類（半装身型+1・全装身型+2 など）・オプション・サイバネティクスの合計。上限 +3（第10章）
- 防御修正を引いた結果が0以下なら **1**。回避スペシャルなら 0
- 「庇う」で肩代わりする時は、肩代わりする側の防御修正を使う

#### 回復

- サブ行動「アイテム」：回復薬でHP +3（1つにつき）
- スタイル「支援」の技（第7章）
- ダウンタイムの休息で全回復

### 5-6　終了条件

| 結果 | 条件 | 処理 |
|---|---|---|
| **討伐成功** | 核HPが0 | 怪異は消滅する |
| **封印成功** | 封印ゲージが上限に達した（特級） | 管理封印状態。シナリオクリア |
| **撤退／制限ラウンド超過** | 制限ラウンドを超えた、または全員で撤退を宣言した | 怪異は姿を消し、一時的に退く。層HPは次回全回復。**核HPは持ち越し**。全PCの信念−1・哀愁+1 |
| **全滅** | 全PCが気絶 | GMは後日談を語る。シナリオは失敗で終わる |

### 6-5　専心

任意の能力値を2つ選び、専心を付ける。同じ能力値に2つは付けられない。専心を付けた能力値は、判定でダイスを1個多く振る。

> **例：** 背景「鋼の肉体」（体C・疾C）→ 傭兵 → 突撃型（体→B）→ 専心を体と察に → **体B＋専心**（4d6）・疾C・察D＋専心（2d6）。体は「突撃屋の中でも一番硬い男」、察は「戦場で磨いた嗅覚」を表す。

### 6-6　作成例

#### 【祓部・古怪班】九条 灯（くじょう あかり）Lv1

所属：祓部／背景：神社育ち／配属：古怪班／覚醒：先天覚醒型（魂）
能力値：体D・疾D・**識B**・判D・**察C**・術D・**魂C**
専心：識・魂／主スタイル：**解明**／副スタイル：封印（Lv3で解禁）
初期ギフト：鍵の直感／言語：得意 Monyx・苦手 Igniscript／HP 10／装備：符（魔導型・武器修正+1）＋霊素探知器

> 調査で最も頼れる。【識】3d6＋専心で **4d6**、解明判定は「文献照合」で+2。だが調べるたびに**哀愁**が積む。臨界すれば調査の手が止まる。祓部データベースは強いが、任務命令には逆らえない。

#### 【傭兵・突撃型】灰島 鉄（はいじま てつ）Lv1

所属：傭兵／背景：鋼の肉体／配属：突撃型／覚醒：ショック覚醒型
能力値：**体B**・**疾C**・識D・判D・察D・術D・魂D
専心：体・疾／主スタイル：**重撃**／副スタイル：斬撃（Lv3で解禁）
初期ギフト：装備の鬼／HP 16（10＋体B 4＋鋼の肉体 2）／装備：両手斧（半装身型・武器修正+2。傭兵特典で1ランク上）

> 層を割る役。【体】3d6＋専心で **4d6**、「重撃」でダメージ+2。ほぼ必ず出目6を選びたくなるが、選ぶたびに**怒り**+3。臨界すれば1ラウンド、最寄りの敵へ最大火力しか撃てなくなる。仲間が庇えない位置にいたら事故が起きる。

#### 【無所属・退魔師】霧生（きりゅう）Lv1

所属：無所属／背景：元実験体／配属：退魔師／覚醒：実験覚醒型
能力値：体D・疾D・識D・判D・**察D＋専心**・術D・**魂B＋専心**
専心：魂（背景固定）・察／主スタイル：**異能**／副スタイル：感知（Lv3で解禁）
初期ギフト：怪異の残響／HP 10／装備：ナックル（武装型・武器修正+1）

> 火力は「発現」で達成値+2。ただし1回ごとに**渇望**が+2に加えて出目分乗る。渇望臨界はコスト倍。元実験体なので渇望の覚醒ギフトを1段階早く使える＝**あえて渇望を積みに行くビルド**が成立する。法的保護はない。

## 第7章　スタイル

> *「肩書きは名刺に書け。夜に出る時は、戦い方だけ持っていけ。」*

### 7-1　考え方

**スタイル**は討伐者の「戦い方・振る舞い」だ。所属・配属・背景とは独立しており、**誰でも全スタイルにアクセスできる**。祓部の狙撃手も、無所属の封印術者も作れる。所属・配属・背景は「世界の中での立場・使えるリソース・ロールプレイ」を決め、スタイルは「卓の上で何ができるか」を決める。

### 7-2　取得と段位

キャラクターは**主スタイル1つ・副スタイル1つ**を選ぶ。各スタイルには**段位I／II／III**があり、段位ごとに1つの**技**を得る。

<!-- table:style-unlock -->
| レベル | 解禁 | 使える技の数 |
|---|---|---|
| 1 | 主スタイル 段位I | 1 |
| 3 | 副スタイル 段位I | 2 |
| 5 | 主スタイル 段位II | 3 |
| 8 | 副スタイル 段位II | 4 |
| 10 | 主スタイル 段位III | 5 |
| 13 | 第三スタイル 段位I | 6 |
| 16 | 副スタイル 段位III | 7 |
| 20 | **極**（主スタイル段位IIIの技の使用回数が2倍） | 7 |
<!-- /table -->

技は上位段位を得ても失わない。段位IIIの技は強力な代わりに「1シナリオ1回」などの回数制限を持つ。

## 第9章　魔法と異能

> *「大きな魔法を使えば、大きな怪異が生まれる。それでも撃つなら、責任は撃った者にある。」*

### 9-1　魔法とは

魔法は「世界のソースコードへの直接介入」だ。素養が必要で、訓練によって習得する。電気やガスと同等のインフラとして位置づけられ、資格制度と安全基準が存在する。

魔法で怪異を倒すことと、魔法で怪異を生むことは表裏一体だ。

### 9-2　魔法判定

魔法行使は【術】で判定する。共鳴は**渇望**。

| 用途 | 効果 |
|---|---|
| **攻撃魔法** | ダメージ ＝ 達成値 ＋ 術式修正 − 防御力。術式修正は魔導具の武器修正（第10章）に相当する |
| **支援魔法** | 味方1人の次の判定に +1、または回復薬1つ分（HP +3）の回復 |
| **干渉魔法** | 基本行動「干渉」と同じ（層特性1つを次のラウンド終了まで無効化） |
| **調査魔法** | 調査判定を【術】で行う。NGTなら電子情報の追跡に +1 など、言語の得意状況が乗る |

魔法の効果は上の4分類で表現する。PLが「こういう魔法を使いたい」と言ったら、GMはどれに当たるかを決めて判定させる。

### 9-3　怪異誘発判定

次のいずれかが起きた時、GMは**怪異誘発判定**を行う。

- 魔法判定で**スペシャル**（出目6）を選んだ
- 魔法判定を**押し通し**で成功させた
- 「大術式」など、技が指定している
- 魔法判定に**ファンブル**した

GMが1d6を振り、閾値以上なら周辺に**五級〜四級の怪異**が生まれる。生まれた怪異は今の討伐フェーズに介入するか（脅威度+1として扱う）、後日の依頼になる。

| 術ランク | 怪異が生まれる出目 | 確率 |
|---|---|---|
| D | 4以上 | 約50% |
| C | 5以上 | 約33% |
| B | 6のみ | 約17% |
| A以上 | 生まれない | 0% |

「魔道資格者」の背景は閾値を1段階改善する（D→Cの扱い、など）。「魔法師の直感」のギフトはスペシャル時の誘発判定を免除する。

> **例：** 術Cのアカリが広域術式を撃ち、出目6を選んだ。ダメージは伸びたが、GMは1d6を振る。5——四級怪異が路地の向こうで産声を上げた。今は脅威度が1上がるだけだが、次のセッションの依頼はそれになる。

### 9-4　禁止魔法

| 禁止対象 | 理由 | 例外 |
|---|---|---|
| **透明化魔法** | 暗殺・窃盗・盗撮など犯罪への悪用リスクが極めて高い | 公的機関が特別に許可した作戦でのみ限定使用可 |
| **召喚魔法** | 存在しないものを現実に呼び出す行為は怪異の発生原理と酷似しており、怪異誘発リスクが非常に高い | 厳格な管理下での研究目的のみ。実戦使用は不可 |

PCが無許可で禁止魔法を使用した場合、社会的制裁（免許停止・指名手配等）が発生する。NPCが使っていれば、それ自体が事件のフラグになる。

### 9-5　魔法言語

魔法使いは通常1つの言語で魔法を行使する。どの言語でも同じ結果を得られるが、アプローチが異なる。

<!-- table:languages -->
| 言語 | 色 | 質感 | 得意な状況（判定 +1） |
|---|---|---|---|
| **P** | — | 汎用基礎言語。全言語と組み合わせ可能 | 魔導具の製造・調整 |
| **Igniscript** | 赤 | 燃やす・爆発・熱変容。力任せで直線的 | 単体目標・集中火力 |
| **Lupis Surf** | 青 | 流す・包む・圧力で押し動かす | 複数目標・範囲効果 |
| **Ivyo** | 緑 | 育てる・自然サイクルに乗せる | 持続時間が重要な場面 |
| **NGT** | 黄 | 加速・電気的処理・情報解析 | 電子機器・通信・情報網への干渉 |
| **Monyx** | 無色 | 最小限の術式で組む | 魔導具の調整・封印処理 |
| **P:** | 紫 | 弱体化・妨害・封印。Pの派生 | 怪異のルールへの直接干渉・封印 |
| **P'** | 桃 | 回復・強化・修復。Pの派生 | 回復・能力の一時強化 |
<!-- /table -->

キャラクター作成時に**得意**と**苦手**を同じ数だけ選ぶ（0〜3個ずつ）。得意言語の得意状況では判定 +1、苦手言語を使わざるを得ない場面では −1。P: と P' は P の習得が前提だ。

### 9-6　異能

異能は「内側から生まれる力」だ。怪異と同じ発生原理を持ち、魔法とは根本的に異なる。

| 項目 | 魔法 | 異能 |
|---|---|---|
| 原理 | 外部（世界への介入） | 内部（自身の変質） |
| 再現性 | 高い | 低い |
| 習得方法 | 訓練と素養 | 体験と執着 |
| リスク | 怪異を生む | 使用者が変質する |

異能を持つかどうかはキャラクター作成時にPLが決める。異能の内容（「触れたものの記憶を読む」「影を伸ばす」など）は自由に設定し、GMと相談して**攻撃／支援／干渉／調査**のどれに当たるかを決める。

**異能の発動は【魂】で判定する。共鳴は渇望。**

| 結果 | 効果 |
|---|---|
| スペシャル | 効果が最大出力で発揮。渇望 +3 |
| 成功 | 効果発揮。渇望は選んだ出目−3 |
| 失敗 | 効果なし。渇望 +1 |
| ファンブル | 制御不能な効果が発動する（GM決定）。渇望 +2・恐怖 +2 |

異能は魔法と違って怪異を生まない。代わりに、使うたびに使用者を怪異に近づける。渇望メーターの覚醒ギフト（第8章）と、スタイル「異能」（第7章）が、その道の先にあるものだ。

信念ポイントは技のコスト（「怪異化」など）や、GMが提示する「信念を賭ける」場面で使う。0になった討伐者は、次のダウンタイムで「休息」を選ばなければならない。

### 11-5　ダウンタイム

シナリオ間の休息期間。PLは以下から**2つ**まで選ぶ。

| 行動 | 効果 |
|---|---|
| **休息** | HP全回復。負傷（ダイス−1個）を解除。全メーターを半分（切り捨て）に |
| **訓練** | 次のレベルアップ時、専心を1つ追加で得る（Lv2・6・11・17の専心とは別。1キャンペーン2回まで） |
| **装備整備** | 破損装備の修復。CP予算内での装備入れ替え |
| **施術** | サイバネティクスの追加（GM許可） |
| **情報収集** | 次シナリオで解明鍵①を最初から持って始める |
| **人脈構築** | NPC関係を1段階深める。次シナリオで「ネットワーク」ギフトと同じ効果を1回 |
| **闇市場アクセス** | 非正規の装備・素材の入手（GMがリスクを提示する） |

### 11-6　負傷と回復

戦闘やシナリオ中に**重傷**（HP3以下）を負った場合、GMは関連する能力値に**負傷**を付与できる。ダウンタイムの「休息」で解除される。

| 状況 | 負傷の例 |
|---|---|
| 腕の重傷 | 体 |
| 足の負傷 | 疾 |
| 精神的ショック | 魂 |
| 怪異の呪い | GM指定 |

### 12-3　スケーリング式

上の表は**PC4人・Lv1〜3**を基準にしている。人数やレベルが違う時は次の式で調整する。

```
怪異の総耐久（層HP合計＋核HP） ≒ 等級表の値 × PC人数 ÷ 4
脅威度 ≒ PC平均最大HP ÷ 2 − 2（最低3）
```

等級表の値は「PC4人 × 1人あたりの1ラウンド期待ダメージ **5**（達成値4〜6＋武器修正1〜3−層防御1〜2） × 目標ラウンド数」から、制限ラウンドに余裕を持たせるため1割ほど軽く丸めたものだ（三級なら 60→52）。**等級表とサンプル怪異の値を正とする。** 卓の平均武器修正が+3を超えるなら、総耐久を2割増やす。

| 例 | 総耐久 | 内訳の例 |
|---|---|---|
| PC3人・三級・3ラウンド | 39 | 層10＋層10＋核19 |
| PC4人・三級・3ラウンド | 52（等級表どおり） | 層14＋層14＋核24 |
| PC5人・二級・4ラウンド | 88 | 層22＋層22＋核44 |

**制限ラウンドは想定ラウンド＋1**にする。余裕が1ラウンドあれば、失敗した判定や臨界の代償を吸収できる。

### 12-5　怪異の手番の決め方

GMは毎ラウンド、次の優先順で行動を選ぶ。迷ったら【襲撃】。

1. 層特性が行動を指定している → それに従う
2. 最上層のHPが半分以下で、再生を持つ → **再生**
3. PCの誰かのメーターが8以上 → **侵蝕**（そのメーターを指定して臨界に追い込む）
4. HP3以下のPCがいて、貫通が演出上ふさわしい → **貫通**
5. 上記以外 → **襲撃**

「侵蝕」は強い。使いすぎると卓が萎える。1戦闘に1〜2回にとどめる。

### 12-6　特級怪異と封印ゲージ

特級怪異は討伐できない。核HPの代わりに**封印ゲージ**（上限30）を使う。

- 封印ゲージは【浄化】行動（+2）、「封印術式」（+5）、「大浄化」（+4）、解明鍵1つにつき +2 で溜まる
- 封印ゲージが上限に達すると**管理封印状態**になり、シナリオクリア
- 制限ラウンドはない。代わりに、怪異の手番が3回過ぎるごとに脅威度 +2
- 防壁層を剥がす必要はないが、層が健在な間は封印ゲージの上昇が半減する

### 12-7　解明鍵の作り方

| 鍵 | 手がかりを置く場所の例 | 判定 |
|---|---|---|
| ① 発生源 | 文献・SNSの初出・元の噂を知るNPC | 識 |
| ② ルール | 被害者の共通点・現場の痕跡・生存者の証言 | 察・判 |
| ③ 核の所在 | 被害の中心地・持ち物・写り込んだ物 | 察・識 |
| ④ 弱点 | ①〜③を組み合わせた推論。古い怪異なら伝承の対処法 | 判 |

各鍵に**2つ以上の入手経路**を用意する。1つの経路で失敗しても、押し通しか別経路で必ず届くようにする。

### 12-8　怪異予兆カードの例

| 公開条件 | 公開効果 | 秘密情報 |
|---|---|---|
| 解明鍵②を得た時 | 防壁層の特性を1つ、その場で無効化する | あなたはこの怪異のルールを、子供の頃に一度踏んでいる |
| 哀愁メーターが5以上になった時 | 解明鍵を1つ追加で得る | 被害者の1人は、あなたが昔見捨てた相手だ |

| 恐怖メーターが臨界に達した時 | 代償を受けない | あなたは以前、この怪異から逃げて生き延びた唯一の人間だ |

### 12-9　改造個体と別個体の運用

- **改造個体**：解明鍵②または④の判定を困難（目標値5）にし、成功時に「決定的に食い違う一点」を告げる
- **別個体**：4鍵のうちGMが指定する1〜2個を無効にし、正しい鍵を改めて取らせる。制限ラウンドは減らさない
- どちらも、無所属の「改造個体センサー」に正直に答える。センサーは信頼できる道具でなければ意味がない

## 第14章　GMの心得

### 14-1　六つの原則

> 調査なしの討伐は自殺行為だ
> 解明なしの討伐は自殺行為だ
> ルールを破れば破るほど逃げられなくなる
> 強さだけで解決できる怪異は存在しない
> 知識が命を救う。無知が人を殺す
> 話しても誰も信じてくれない。それがこの仕事だ

これはプレイヤーへの警句であると同時に、GMへの設計指針だ。**調べた者が報われ、調べなかった者が痛い目を見る**ように、シナリオを組む。

### 14-2　詰ませない

- 解明鍵には必ず2つ以上の経路を置く
- 失敗は「進行停止」ではなく「悪化」で処理する。時間・手がかり・HP・共鳴のどれかを削る
- 押し通しの存在をPLに思い出させる。「共鳴を払って通すか？」と聞いてよい
- 討伐フェーズが長引いたら、制限ラウンド超過＝撤退で区切る。核HPは持ち越されるので、次の挑戦は楽になる

### 14-3　共鳴の見せ方

- メーターは卓に公開する。誰かが8を超えたら、GMは「それが見える」演出をする——手が震える、目が据わる、声が低くなる
- 臨界は罰ではなく山場だ。代償を告げる時は、そのPCに1シーンの主役を与える
- 浄化と支援を担うPCの活躍を意識的に作る。「あの時浄化してくれなければ」と言われる場面を用意する

### 14-4　テストプレイのチェック観点

このルールはテストプレイで削る前提で書かれている。1卓回したら、次の点を確認する。

1. **判定回数**——1セッション20〜30回に収まったか
2. **出目の選択に悩んだか**——毎回6を選ぶだけなら、共鳴の重みが足りない。毎回4しか選べないなら重すぎる
3. **命中率**——体感で5割を超えたか
4. **即死**——怪異の手番1回でPCが落ちなかったか（落ちるなら脅威度を下げる）
5. **戦闘の長さ**——想定ラウンド数に収まったか。超えるなら層HPを削る
6. **臨界**——1セッションで1〜2回起きたか。0回なら上昇量が足りず、4回以上なら多すぎる
7. **押し通し**——使われたか。使われないなら失敗の痛みが足りない
8. **「何をしたらいいか分からない」瞬間**——なかったか

**最初のテストプレイは三級怪異（13-2）・PC3〜4人・Lv1で行う。** まず回してから、面白くない部分を引き算する。

5. 共鳴：**選んだ出目−3** を対応メーターへ（失敗は0、ファンブルは恐怖+2）
6. 失敗したら**押し通し**可：対応メーター+3で達成値4の成功に

## 付録B　v4.0からの変更点と移行

### B-1　変更点

| 領域 | v4.0 | v5.0 | 理由 |
|---|---|---|---|
| 達成値 | 振った中から1個選ぶ（最大を選ぶだけ） | 同じ。ただし**選んだ出目が共鳴量になる**ので選択が発生する | 選択の実質化 |
| 共鳴ダイス | 別に1個選ぶ。出目は無関係 | **廃止** | 死に要素 |
| 段階（＋/−）13ステップ | 達成値に±1 | **廃止 → 専心／負傷（ダイス±1個）** | 管理コストに効果が見合わない |
| 修正上限 | +4 | **+3** | 達成値がダメージ直結のため |
| ファンブル | 出目1 | **全部3以下かつ1あり** | 高ランクでも消えない事故 |
| 失敗 | 失敗のまま | **押し通し**で共鳴を払って成功に変えられる | 詰み防止をシステムで担保 |
| 共鳴の上昇先 | 文脈表を参照 | **行為の種類で一意** | 参照の往復を削る |
| スキル | 6軸74個／生涯4個取得 | **廃止 → スタイル9種×段位3（27技）** | 定義の9割が卓に出ない |
| 効果の記述 | 自由文（エンジンが文字列マッチ） | **部品合成式（構造化データ）** | 追加のたびにエンジン改修が必要だった |
| 護衛 | 個体2〜3体（特性8種・行動5種） | **防壁層1〜3（共有HP・特性1つ）** | 処理量が卓とWebの両方で過大 |
| リアクション | 基本行動（回避・援護・カウンター）として1ラウンド1回 | **基本行動としては廃止 → 怪異の手番での回避判定に統合。**技のタイミングとしては残る（「未来視」のみ） | 割り込み処理の削減 |
| 怪異誘発判定 | 失敗時・大規模魔法時 | **スペシャル選択時・押し通し時・ファンブル時** | 「大きく撃つほど怪異を生む」の直結 |
| 覚醒ギフト | 6メーター×3段階 | 同じ構成で効果を v5.0 の戦闘に合わせて刷新。**取得不要、段階で自動解放** | — |
| サイバネティクス | 改造CP・侵食率依存 | **装備CPから購入・常時共鳴で表現**。オプションルール化 | 侵食率の廃止方針に合わせる |
| レベル | 1〜20（10以降は空欄） | **1〜20を全て定義**。スタイル解禁を Lv13・16・20 に配置 | — |

**変えないもの：** 7能力値、ランクD〜S、所属3種、背景6種、配属12種、覚醒4種、共鳴メーター6種、信念ポイント、CP予算、レベル上限20、魔法言語、怪異の等級体系。**既存の投稿キャラクターの能力値・所属・背景・配属・覚醒はそのまま通用する。**

# 電脳怪異譚 KAI-I//KILL — キャラクター造形ガイド v1.0

> このガイドは、KAI-I//KILLの世界でキャラクターを造形するための指針である。
> 「どんな立場・背景・動機の人物が、この世界で討伐者として物語を始められるか」をまとめている。
> 数値や能力値のシステム仕様は別途ルールブック／ゲーム側を参照すること。

---

## はじめに — 造形できるキャラクター

キャラクターを作り始める前に、この世界で物語を始められるキャラクター像を確認しておくこと。KAI-I//KILLは現代伝奇アクションの舞台であり、キャラクターは**怪異と戦う討伐者の一人**である。英雄でも超人でもない。

---

## 造形できるキャラクター（OK例）

| 方向性 | 例 | ポイント |
|:-------|:---|:--------|
| **正規の若手討伐者** | 祓部の祓士。訓練を終えたばかり | 組織の歯車として動きながら、現場で成長する |
| **企業に雇われた傭兵** | 雷禽重工の装備を使う突撃型 | 契約と実績の世界。二つ名はこれから勝ち取る |
| **フリーの傭兵** | 《Anonymous》の駆け出し。まだ名前もない | 仕事を選びながら実力を積む段階 |
| **裏社会から這い上がった無所属** | 底澱のスラムで育った路地裏の犬 | 何も持たないが生き延びてきた |
| **元祓部の脱走兵** | 組織に幻滅して抜けた。追われている | 過去の知識と追跡のリスクを天秤にかける |
| **独学の退魔師** | 神社の血筋だが祓部には入らなかった | 古い知識はあるが、組織の後ろ盾はない |
| **怪異の被害者から討伐者へ** | 家族を怪異に殺され、復讐を誓った | 強い動機があるが、未熟さと向き合う |
| **過去に囚われた討伐者** | 実験施設から逃げ出してきた | 力はあるが制御が不安定。自分自身への恐怖を抱えている |
| **調査専門の知識型** | 民俗学者くずれ。戦えないが怪異を解き明かす | 解明で輝く。戦闘は仲間に任せる |
| **サイバネティクス改造済み** | 片腕が義肢。蒼鉄機工の正規品 | 改造の恩恵と拒絶反応の代償がある |

**共通する「いいキャラクター」の条件：**

- **成長の余地がある** — 最初から完成していない。物語を通じて強くなる
- **弱点がある** — 何かが欠けている。仲間が必要な理由がある
- **動機がある** — なぜ怪異と戦うのか、理由が1つ以上ある
- **世界に足がついている** — この社会の中で生きている実感がある

## 造形できないキャラクター（禁止事項）

| # | NG | 理由 |
|:--|:---|:-----|
| 1 | **大祓主・祓主・禊士** | 開始時点では祓士が上限。指揮官クラスは別の立場（NPC・上位者） |
| 2 | **上級祓士で開始** | 通常の祓士より1段上。駆け出しとしては不適切 |
| 3 | **《Anonymous》最上位ランク** | 業界最高峰〜伝説級。到達する「かもしれない」目標であって、出発点ではない |
| 4 | **御柱（みはしら）** | 大祓主直轄の伝説的存在。開始時点の立場ではない |
| 5 | **怪異そのもの・怪異に完全に変質した存在** | 「人間側」で物語を始めるのが前提。怪異側に落ちたら物語は終わる |
| 6 | **複数の特級怪異を単独撃破した経歴** | 世界内で最も危険な存在。駆け出しがそんな経歴を持つのは不自然 |
| 7 | **侵食が手遅れの段階で開始** | 物語が始まる前に終わっている。侵食の恐怖を味わう余地がない |
| 8 | **元禊士の脱走兵** | 「元禊士」の知識と人脈は物語のバランスを壊す |
| 9 | **蜃気楼工廠の装備を所持して開始** | 怪異核素材の装備は危険すぎる。物語を通じて入手するもの |
| 10 | **全装身型・戦闘用搭乗型で開始** | 上位装備は成長の先にあるもの |
| 11 | **全身改造（サイバネティクス最上位）で開始** | 全身改造は代償が重い。物語の末に辿り着くもの |
| 12 | **他キャラクターの記憶を操作できる設定** | 記憶操作は上位NPCの領域。仲間同士の関係を壊す |

## 非推奨（造形できるが、避けたほうがいいもの）

| # | 非推奨 | 理由 | こうすると良くなる |
|:--|:-------|:-----|:-----------------|
| 1 | **「最強」を自称する設定** | 成長の余地がない。他キャラを見下す構造になりやすい | 「強くなりたい」「まだ足りない」という動機にする |
| 2 | **孤高すぎて仲間と絡めない** | 複数人で物語を紡ぐゲームである | 一匹狼でも「組まざるを得ない理由」を1つ用意する |
| 3 | **過去が重すぎて動けない** | トラウマは良い設定だが、行動不能になると物語が止まる | 「傷はあるが、それでも前に出る」にする |
| 4 | **現実の特定組織・事件の直接的パロディ** | 世界観の没入を妨げる | KAI-I//KILLの固有設定に沿って翻案すること |
| 5 | **怪異と友好的な関係を最初から持っている** | 怪異は「集合的な噂が実体化したもの」。友好関係は極めて稀 | 「理解・共感」として表現する。友好ではなく複雑な感情 |
| 6 | **魔法言語をすべて得意にする** | 得意と苦手は同数が基本。全得意は不可 | 得意2〜3 + 苦手2〜3 が一般的 |
| 7 | **所属と矛盾する行動指針** | 祓部なのに組織を無視する、傭兵なのに契約を守らない等 | 「葛藤」は良いが「最初から破綻」はNG |

## 背景設定のコツ — 「なぜ戦うのか」

キャラクターは全員、怪異と戦う理由を持っている。以下のうち**1つ以上**を設定に含めること。

| 動機の型 | 例 |
|:---------|:---|
| **喪失** | 家族・友人・恩師を怪異に奪われた |
| **使命** | 組織から任務を受けている。職務として |
| **贖罪** | 過去に怪異を生む原因を作ってしまった |
| **知的欲求** | 怪異の謎を解き明かしたい |
| **生存** | 怪異に追われている。戦わなければ死ぬ |
| **復讐** | 特定の怪異、または怪異を利用した者への報復 |
| **保護** | 守りたい人・場所がある |
| **自分自身への恐怖** | 自分の中にある力が怪異に近い。制御するために戦う |

**NGな動機：**

- 「特にない」「なんとなく」 — 物語に参加する理由がなくなる
- 「世界を救う」 — スケールが大きすぎる。キャラクターは一人の討伐者

# 電脳怪異譚 KAI-I//KILL — キャラクター製作ガイドライン v1.0

> このガイドは、初めてキャラクターを作る人でも迷わず進められるよう、選択肢と手順をまとめたものである。

---

## はじめに — PCとして作れるキャラクター

キャラクターを作り始める前に、この世界で「プレイヤーキャラクター（PC）」として作れるもの・作れないものを確認しておくこと。
KAI-I//KILLは現代伝奇アクションTRPGであり、PCは**怪異と戦う討伐者の一人**である。英雄でも超人でもない。

---

### 作れるキャラクター（OK例）

| 方向性 | 例 | ポイント |
|:-------|:---|:--------|
| **正規の若手討伐者** | 祓部の祓士。訓練を終えたばかり | 組織の歯車として動きながら、現場で成長する |
| **企業に雇われた傭兵** | 雷禽重工の装備を使う突撃型 | 契約と実績の世界。二つ名はこれから勝ち取る |
| **フリーの傭兵** | 《Anonymous》Dランク。まだ名前もない | 仕事を選びながら実力を積む段階 |
| **裏社会から這い上がった無所属** | 底澱のスラムで育った路地裏の犬 | 何も持たないが生き延びてきた |
| **元祓部の脱走兵** | 組織に幻滅して抜けた。追われている | 過去の知識と追跡のリスクを天秤にかける |
| **独学の退魔師** | 神社の血筋だが祓部には入らなかった | 古い知識はあるが、組織の後ろ盾はない |
| **怪異の被害者から討伐者へ** | 家族を怪異に殺され、復讐を誓った | 強い動機があるが、未熟さと向き合う |
| **異能に目覚めた一般人** | 実験の被験者だった。逃げ出してきた | 力はあるが制御が不安定。怪異に近い自分への恐怖 |
| **調査専門の知識型** | 民俗学者くずれ。戦えないが怪異を解き明かす | 解明フェーズで輝く。戦闘は仲間に任せる |
| **サイバネティクス改造済み** | 片腕が義肢。蒼鉄機工の正規品 | 改造の恩恵と拒絶反応の代償がある |

**共通する「いいPC」の条件：**

- **成長の余地がある** — 最初から完成していない。セッションを通じて強くなる
- **弱点がある** — 何かが欠けている。仲間が必要な理由がある
- **動機がある** — なぜ怪異と戦うのか、理由が1つ以上ある
- **世界に足がついている** — この社会の中で生きている実感がある

### 作れないキャラクター（NG例）

#### 絶対NG — 世界観・ゲームバランスを壊すもの

| NG | 理由 |
|:---|:-----|
| **大祓主・祓主・禊士** | PC開始ランクは祓士が上限。指揮官クラスはNPC専用 |
| **《Anonymous》Sランク（冠名）** | 特級怪異を複数回生き延びた伝説。PCが到達する「かもしれない」目標であって、出発点ではない |
| **御柱（みはしら）** | 大祓主直轄の伝説的存在。NPC専用 |
| **教団の幹部・構成員** | 教団は敵対勢力。PCとして操作する立場にない |
| **怪異そのもの・怪異に完全に変質した存在** | PCは「人間側」である。怪異側に落ちたらキャラクターの物語は終わる |
| **複数の特級怪異を単独撃破した経歴** | ゲーム内で最も危険な存在。初期PCがそんな経歴を持つのは不自然 |
| **侵食率80%以上で開始** | 物語が始まる前に終わっている。侵食の恐怖を味わう余地がない |

#### 強いNG — GMの許可なしには作れないもの

| NG | 理由 | GM許可があれば |
|:---|:-----|:-------------|
| **上級祓士で開始** | 通常の祓士より1段上。バランスに影響 | 経験者卓で、他PCも同格なら検討可 |
| **《Anonymous》Aランク** | 業界最高峰の実力者。初期PCとしては強すぎる | 高レベル開始キャンペーンなら可 |
| **元禊士の脱走兵** | 強力な経歴。「元禊士」の知識と人脈がゲームを壊す可能性 | 代償が重い設定とセットなら検討可 |
| **蜃気楼工廠の装備を所持して開始** | 怪異核素材の装備は危険すぎる。物語を通じて入手するもの | シナリオの核心に関わるなら可 |
| **全装身型・戦闘用搭乗型で開始** | 全装身型はLv5、戦闘用搭乗型はLv7で解禁。初期PCには早い | 特殊な背景設定とセットで、GMが認めれば可 |
| **サイバネティクス等級Ⅲで開始** | 全身改造は代償が重い。物語の末に辿り着くもの | 「改造の代償」を前面に出す設計なら検討可 |
| **他PCの記憶を操作できる設定** | 祓部管理部の記憶操作はNPC権限。PCが持つとPvPの原因になる | GMが管理するNPC能力として使うなら可 |

#### やんわりNG — 避けたほうがいいもの

| NG | 理由 | 代わりにこうする |
|:---|:-----|:----------------|
| **「最強」を自称する設定** | 成長の余地がない。他PCを見下す構造になりやすい | 「強くなりたい」「まだ足りない」という動機にする |
| **孤高すぎて仲間と絡めない** | TRPGはチーム。一匹狼でも「組まざるを得ない理由」が必要 | 「単独では厳しい任務が来た」という導入が使える |
| **過去が重すぎて動けない** | トラウマは良い設定だが、行動不能に陥るほどだと卓が止まる | 「傷はあるが、それでも前に出る」にする |
| **設定が現実の特定組織・事件の直接的パロディ** | 世界観の没入を妨げる | KAI-I//KILLの固有設定に沿って翻案する |
| **怪異と友好的な関係を最初から持っている** | 怪異は「集合的な噂が実体化したもの」。友好関係は極めて稀な例外 | 「怪異に対する複雑な感情」として表現する。友好ではなく理解・共感 |
| **魔法言語をすべて得意にする** | ルール上、得意と苦手は同数。全得意は不可 | 得意2〜3 + 苦手2〜3 が一般的 |
| **所属と矛盾する行動指針** | 例：祓部なのに組織を無視する、傭兵なのに契約を守らない | 「組織の中で葛藤する」のは良いが、「最初から破綻している」のはNG |

### 背景設定のコツ — 「なぜ戦うのか」

PCは全員、怪異と戦う理由を持っている。以下のうち**1つ以上**を設定に含めること。

| 動機の型 | 例 |
|:---------|:---|
| **喪失** | 家族・友人・恩師を怪異に奪われた |
| **使命** | 組織から任務を受けている。職務として |
| **贖罪** | 過去に怪異を生む原因を作ってしまった |
| **知的欲求** | 怪異の謎を解き明かしたい |
| **生存** | 怪異に追われている。戦わなければ死ぬ |
| **復讐** | 特定の怪異、または怪異を利用した者への報復 |
| **保護** | 守りたい人・場所がある |
| **自分自身への恐怖** | 異能を持つ自分が怪異に近い。制御するために戦う |

**NGな動機：**

- 「特にない」「なんとなく」 — 物語に参加する理由がなくなる
- 「世界を救う」 — スケールが大きすぎる。PCは一人の討伐者
- 「怪異になりたい」 — PCは人間側。これは教団の思想

### パーティ構成の指針

セッションは通常3〜5人のPCで行う。以下のバランスが理想。

| 役割 | 必要数 | 担当する場面 |
|:-----|:------|:------------|
| **調査担当**（識・察が高い） | 1〜2人 | 調査フェーズで情報を集める |
| **解明担当**（判・識が高い） | 1人 | 解明宣言の判定を行う |
| **戦闘担当**（体・疾が高い） | 1〜2人 | 討伐フェーズで前に出る |
| **支援担当**（術・魂が高い） | 0〜1人 | 魔法支援・信念回復・封印 |

- 全員が戦闘特化だと調査フェーズで詰む
- 全員が調査特化だと討伐フェーズで壊滅する
- **1人のPCが2つの役割を兼ねる**のが現実的（例：調査+戦闘、解明+支援）

---

### 所属の混成について

同じパーティに祓部・傭兵・無所属が混在していてよい。
むしろKAI-I//KILLの世界では、**人手不足の祓部が傭兵や無所属と組まざるを得ない**のが日常。

| 混成パターン | 物語的な理由 |
|:------------|:------------|
| 祓部 + 傭兵 | 祓部が人手不足で傭兵に外注した |
| 祓部 + 無所属 | 現場で偶然合流した。あるいは非公式に協力を求めた |
| 傭兵 + 無所属 | 同じ依頼に別ルートで辿り着いた |
| 全員同じ所属 | 同じ組織の仲間。最もまとまりやすい |
| 全員バラバラ | 最も混沌とするが、最もKAI-I//KILLらしい |

**注意：** 所属が異なるPCは、互いの立場を理解したうえで「それでも組む理由」を持つこと。
祓部のPCが無所属のPCを「逮捕すべき対象」として扱い続けると卓が崩壊する。

## 製作の流れ（全12ステップ）

```
STEP 1   能力値初期化 ── 全7能力値をランクDでスタート
STEP 2   背景を選ぶ ─── 出自を決め、能力値2つがCに上昇
STEP 3   所属を選ぶ ─── 祓部・傭兵・無所属の三択
STEP 4   配属を選ぶ ─── 所属内の専門班を決定、能力値1つがBに上昇
STEP 5   覚醒パターン ─ 力に目覚めた経緯を選択
STEP 6   初期ギフト ─── 天賦の才能を1つ選択
STEP 7   武器型を選ぶ ─ 戦闘スタイルを決定（5型）
STEP 8   スキル選択 ─── 初期2枠を埋める
STEP 9   段階調整 ──── 任意の能力値2つに+段階を付与
STEP 10  装備を選ぶ ─── CP予算内で武器・カスタムを決定
STEP 11  信念を設定 ─── 信念ポイント5点で開始
STEP 12  仕上げ ─────── 名前・外見・過去を記入
```

---

## STEP 1 ─ 能力値

7つの能力値すべてが **ランクD（1d6）** からスタートする。
背景・配属・覚醒パターンの選択で段階的に上昇していく。

| 能力値 | 略 | 役割 |
|:---|:---:|:---|
| **体** | 体 | 格闘・突破・物理耐久 |
| **疾** | 疾 | 先手・回避・追跡 |
| **識** | 識 | 調査・知識・文献解読・解明 |
| **判** | 判 | 解明宣言・看破・戦術判断 |
| **察** | 察 | 怪異感知・観察・証言聴取 |
| **術** | 術 | 魔法行使・魔導具操作 |
| **魂** | 魂 | 信念維持・精神防御・異能発動 |

### ランク体系

```
D- → D → D+ → C- → C → C+ → B- → B → B+ → A- → A → A+ → S
```

| ランク | ダイス数 |
|:---:|:---|
| D | 1d6 |
| C | 2d6 |
| B | 3d6 |
| A | 4d6 |
| S | 4d6＋特典 |

- **+段階**は達成値に+1、**−段階**は達成値に−1
- ファンブル（出目1）・スペシャル（出目6）は段階修正を受けない

---

## STEP 2 ─ 背景（6種から1つ）

出自や経歴を決める。**能力値2つがCに上昇**し、背景スキルが自動で手に入る。

| 背景 | C昇格 | 特殊効果 | 自動スキル |
|:---|:---:|:---|:---|
| **神社育ち** | 察・魂 | 禁足地データベースへの非公式アクセス権。古い怪異の解明鍵①を難易度-1で入手可能 | 禁足地の知恵 |
| **鋼の肉体** | 体・疾 | 武装型・半装身型の装備CP+4。護衛として初回攻撃に+1修正 | 初撃の勘 |
| **都市伝説研究者** | 識・判 | 調査でスペシャル時、追加の解明鍵を入手する可能性がある | 調査ノート |
| **元実験体** | 魂＋異能+1 | 渇望メーターの覚醒ギフトを通常より1段階低いコストで使用可能 | 怪異への親和性 |
| **ハッカー上がり** | 識・疾 | NGT魔法の判定+1。独立型装備のCP+3 | 電子侵入 |
| **魔道資格者** | 術・識 | 選択した魔法言語の+1修正が2状況に拡張。怪異誘発の確率が1ランク改善 | 安全術式 |

### 選び方のポイント

- **前衛で戦いたい** → 鋼の肉体（体・疾が上がり、装備も強化できる）
- **調査・頭脳担当** → 都市伝説研究者 or ハッカー上がり
- **魔法で戦いたい** → 魔道資格者（術が上がる唯一の背景）
- **異能を使いこなしたい** → 元実験体（渇望ギフトのコスト軽減）
- **怪異の気配を察したい** → 神社育ち（察・魂の両方が上がる）

## STEP 3 ─ 所属（3種から1つ）

所属によって立場・行動範囲・特典が大きく変わる。

### 祓部（はらえべ）

公的な怪異対処組織。国家認可の正規討伐者。

- **特典**：識判定+2（調査時、3回/セッション）。援軍要請1回/セッション
- **制約**：行動報告義務。違法改造・闇取引は原則禁止
- **向いている人**：正道で戦いたい。調査が好き。組織の力を使いたい

### 傭兵

企業系・独立系の契約討伐者。依頼ネットワーク《Anonymous》で仕事を受ける。

- **特典**：装備を1ランク上から選択可能。判定コネクション+2（3回/セッション）。初期二つ名+1
- **制約**：契約に縛られる。企業の都合に巻き込まれることがある
- **向いている人**：高い装備性能がほしい。人脈を活かしたい。二つ名に憧れる

### 無所属

組織に属さない独立討伐者。自由だが後ろ盾がない。

- **特典**：察判定に常時+1（空気読み・怪異気配）。裏ルート1回/セッション。改造個体センサー1回/セッション
- **制約**：法的保護なし。報酬も保証もない
- **向いている人**：自由に動きたい。裏社会とのつながりが好き。一匹狼ロールプレイ

---

## STEP 4 ─ 配属（所属ごとに4種から1つ）

配属を決めると**能力値1つがBに上昇**する。ここがキャラクターの最高能力値になることが多い。

### 祓部の班

| 班 | B昇格 | 特徴 |
|:---|:---:|:---|
| **古怪班** | 識→B | 古い怪異専門。古文書解読・民俗学に精通 |
| **新怪班** | 察→B | 現代型怪異・SNS・デジタル領域専門 |
| **封印班** | 魂→B | 禁足地管理・特級怪異の封印を担当 |
| **機動班** | 体→B | 最前線に投入される即応部隊 |

### 傭兵の専門

| 専門 | B昇格 | 特徴 |
|:---|:---:|:---|
| **突撃型** | 体→B | 火力と耐久の前衛担当 |
| **偵察型** | 察→B | 情報収集と分析を行う |
| **技術型** | 術→B | 装備改造と魔法技術の後方支援 |
| **護衛型** | 判→B | 要人護衛・脅威評価・交渉 |

### 無所属の流儀

| 流儀 | B昇格 | 特徴 |
|:---|:---:|:---|
| **野良討伐者** | 体→B | 腕一本で戦う生存特化 |
| **裏社会の住人** | 判→B | 情報網・人脈・交渉・策略 |
| **在野研究者** | 識→B | 独自の研究で怪異に挑む |
| **退魔師** | 魂→B | 独学の祓い術を使う一匹狼 |

### 能力値の重複に注意

背景でCに上がった能力値と配属でBに上がる能力値が**重複しても問題ない**（D→C→Bと順に上がる）。
重複させれば特化型に、散らせばバランス型になる。

## STEP 5 ─ 覚醒パターン（4種から1つ）

怪異に対抗する力にどうやって目覚めたかを選ぶ。

| パターン | 概要 | 特典 |
|:---|:---|:---|
| **先天覚醒型** | 生まれつき素養を持ち、訓練で開花した | 術または魂がC昇格（背景とは別枠） |
| **ショック覚醒型** | 怪異との遭遇がきっかけ。喪失や恨みが原動力 | 喪失/恨みへの判定+1。初期信念+1 |
| **実験覚醒型** | 人体実験で強制的に覚醒させられた | 異能ランク+1。察判定+1（怪異過敏） |
| **接触覚醒型** | 怪異の核や特殊素材に長期間触れ続けた | 察判定に常時+1（怪異気配に鋭敏） |

### 選び方のポイント

- **能力値をさらに伸ばしたい** → 先天覚醒型（追加でCが1つ増える）
- **信念を多く使いたい** → ショック覚醒型（初期信念+1）
- **異能を強く使いたい** → 実験覚醒型（異能ランク上昇）
- **感知特化にしたい** → 接触覚醒型（常時察+1）

---

## STEP 6 ─ 初期ギフト（天賦）（6種から1つ）

キャラクター固有の才能。1つだけ選択する。

| ギフト | 効果 |
|:---|:---|
| **鍵の直感** | 調査中、1日1回だけGMに解明鍵のヒントを要求できる |
| **生還の意地** | HP0になった時、魂判定で成功すれば1HPで耐える（1シナリオ1回） |
| **装備の鬼** | 武装型・半装身型の武器修正が+1される |
| **ネットワーク** | 各都市にNPC情報源を持ち、1シナリオ1回情報提供を受けられる |
| **固有異能** | 異能持ちの場合、初期異能がD→Cに昇格する |
| **魔法師の直感** | 術判定でスペシャル時、怪異誘発判定を免除（1シナリオ2回） |

---

## STEP 7 ─ 武器型（5種から1つ）

戦闘スタイルを決める。所属・配属・覚醒パターンとは**完全に独立**しており、自由に組み合わせられる。

| 武器型 | 戦闘スタイル | 代表的な武器 |
|:---|:---|:---|
| **斬撃型** | 連続攻撃・カウンター | 剣・小刀・太刀・大剣・薙刀・鎖鎌 |
| **打撃型** | 高火力・制圧 | 斧・両手斧・ハルバード・メイス・槍 |
| **射撃型** | 遠距離・精密 | 弓・銃・ボウガン・ライフル・ショットガン |
| **魔導型** | 魔法攻撃・範囲 | 魔導杖・魔導書・符・結界具 |
| **体術型** | 手数・崩し | ナックル・素手格闘 |

### 武器型スキル（レベルで解放）

各武器型に3つの固有スキルがあり、Lv1・3・5で順に解放される。

---

## STEP 8 ─ スキル選択（初期2枠）

Lv1の時点で**2枠**分のスキルを選べる。以下の軸から自由に組み合わせる。

| 軸 | 選択条件 |
|:---|:---|
| **共通スキル** | 誰でも取得可能（応急処置・鼓舞・高速移動・看破・窮地の一撃・戦場鑑定） |
| **所属スキル** | 自分の所属のみ。Lv1/3/5で解放 |
| **配属スキル** | 自分の配属班のみ。Lv1/3/7で解放 |
| **覚醒スキル** | 自分の覚醒パターンのみ。Lv1/5で解放 |
| **武器技能** | 自分の武器型のみ。Lv1/3/5で解放 |

**背景スキルはスロットを消費しない**（自動取得）。

### 選び方のポイント

- **戦闘重視** → 武器技能Lv1 ＋ 共通（窮地の一撃 or 高速移動）
- **調査重視** → 配属スキルLv1 ＋ 共通（看破 or 戦場鑑定）
- **万能型** → 共通スキル2つ（応急処置＋看破など）

---

## STEP 9 ─ 段階調整

任意の能力値**2つ**に**+段階**（達成値+1）を付与できる。
**同じ能力値に2回付与することはできない。**

例：
- 体D+ / 疾D+ とする → 前衛として安定
- 識C+ / 察B+ とする → 調査時に高い達成値

---

## STEP 10 ─ 装備選択

### 装備の分類

| 分類 | 戦闘修正 | リスク | 解禁 |
|:---|:---:|:---:|:---:|
| **武装型** | +1 | 低 | Lv1 |
| **独立型** | 援護+1 | 中 | Lv1 |
| **半装身型** | 攻防+1 | 中 | Lv1 |
| **搭乗型** | 機動力+2 | 中 | Lv1 |
| **全装身型** | +3 | 高 | Lv5 |
| **戦闘用搭乗型** | 三級以下+5 | 非常に高 | Lv7 |

### CP予算

初期（Lv1）のCP予算は **10CP**。
背景による補正がある：

| 条件 | CP補正 |
|:---|:---:|
| 背景「鋼の肉体」＋武装型 or 半装身型 | **+4CP** |
| 背景「ハッカー上がり」＋独立型 | **+3CP** |

### カスタムオプション

ベース武器を選んだうえで、CP予算内でカスタムオプションを追加できる。
オプションにはそれぞれCPコスト・共鳴傾向・リスクが設定されている。

**汎用オプション例：**
- 出力増幅（攻撃+1、2CP）
- 衝撃吸収（被ダメ-1、2CP）
- 感知拡張（察+1、1CP）
- 解明支援（識+1解明限定、2CP）

**分類専用オプション例：**
- 武装型：霊的刃コーティング（怪異特効+1、3CP）
- 独立型：索敵特化AI（察+2偵察限定、3CP）
- 半装身型：魔力直結（術+1行使時、3CP）

---

## STEP 11 ─ 信念ポイント

初期値は **5点**（ショック覚醒型は+1）。
スキルやギフトの発動コストとして使用する。

| レベル帯 | 上限 |
|:---:|:---:|
| Lv1〜4 | 5点 |
| Lv5〜6 | 4点 |
| Lv7〜8 | 3点 |
| Lv9〜10 | 2点 |

レベルが上がるにつれ上限が下がるが、スキルや装備が充実するため総合力は上昇する。

## STEP 12 ─ 仕上げ

以下を記入してキャラクターシートを完成させる。

- **キャラクター名**
- **年齢・性別**
- **外見の特徴**
- **運命（FATE）** — キャラクターが背負う宿命や目的
- **過去の物語** — なぜ討伐者になったのか
- **魔法言語の得意・苦手** — 得意と苦手は同数にする

### 魔法言語（7種）

|:---|:---:|:---|
| **P:** | 紫 | 弱体化・妨害・封印 |

| **Lupis Surf** | 青 | 水流・圧力・流動変化 |
| **Ivyo** | 緑 | 回復・成長・生命力 |

| **Monyx** | 無 | 汎用・最小術式 |

得意言語には+1修正がつく（背景「魔道資格者」なら2状況に拡張）。

## 補足：サイバネティクス（任意）

身体の一部を魔導機関で置換・増強する改造。装備CPとは別枠の**改造CP**で管理する。

| 等級 | 改造CP上限 | 侵食加算 | 内容の例 |
|:---|:---:|:---:|:---|
| **Ⅰ 表層改造** | 3CP | +0% | 戦術HUD・皮下センサー・翻訳機 |
| **Ⅱ 深層改造** | 6CP | +5% | 義腕・脳内チップ・跳躍ブースター |
| **Ⅲ 全置換** | 10CP | +15% | 四肢全交換・全身装甲・脊髄回路 |

- 全キャラ共通で改造CP **3CP** が初期値
- 等級Ⅱ以上は毎セッション開始時に**適応判定**（魂で判定、達成値4以上で成功）が必要
- 一度施術した改造は**除去不可**

戦闘中の行動や体験で6種のメーターが上下する。各メーター最大10点。

| メーター | 上昇する行動 | 10点到達（臨界）の効果 |
|:---|:---|:---|
| **恐怖** | ダメージ受傷・失敗・危機 | 代償を払って覚醒ギフト発動、0にリセット |

| **焦燥** | 速度重視・魔法行使 | 代償を払って覚醒ギフト発動、0にリセット |

| **浄化** | 解明・浄化・祓い行動 | **恩恵のみ：** 恐怖-3、焦燥-3（代償なし） |

## やってはいけないこと

- **能力値を全方位に散らしすぎる** — 1つの得意分野を持つほうが活躍しやすい
- **戦闘スキルだけに偏る** — 調査フェーズが長いゲームなので、調査系も1つは欲しい
- **CP予算を無視して装備を盛る** — 超過するとGMから許可が出ない
- **パーティ内で役割が完全に被る** — 事前に他のプレイヤーと相談するとよい

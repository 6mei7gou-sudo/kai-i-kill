- **Bot連携**（将来、Discord Bot等）

## プロジェクト概要

**IP名：** 怪異キル（kai-i-kill）
**ジャンル：** 近未来架空日本 × ホラー × サイバーパンク
**世界観要点：**
- 怪異（かいい）＝集合的な信念・噂が臨界を超えて物理的な形を取った「バグ」
- 怪異には「核（かく）」と「ルール」がある。ルールを知らずに戦うと死ぬ
- 魔法はインフラ（使いすぎると怪異を生む）
- 異能は内側から生まれる力（使うと自分が怪異に近づいていく）
- 三陣営：祓部（公的機関）・傭兵・無所属

## ★ 主文書：rules_unified.md（v4.0）の要点

`rules_unified.md` はv3.0をベースにアマデウスTRPGを参照して再構成した最新版。
新しいセッションでは **まず `rules_unified.md` を読むこと**。

### v3.0 → v4.0 の主な変更点

| 項目 | v3.0 | v4.0 |
|------|------|------|
| **戦闘の勝利条件** | 討伐クロックを0にする | 核のHPを0にする |
| **護衛のデータ** | 耐久値のみ | HP・攻撃力・防御力・行動値・特性 |
| **連鎖ダメージ** | 護衛の耐久値以上で核にダメージ伝播 | 廃止（機甲士スキル「連鎖衝撃」で余剰ダメージ伝播） |
| **行動経済** | 1ターン1行動 | メイン/サブ/リアクション制 |
| **成長システム** | EP（経験点）蓄積 | レベル制（Lv1〜10） |
| **スキル** | なし（クラス特技のみ） | 6軸スキル（共通/所属/配属/覚醒/背景/武器技能） |
| **クラス制** | 祓士・機甲士・解明師の3クラス | 廃止 → 所属×配属×覚醒×背景×武器型の組合せ |
| **装備予算** | 固定CP | レベル連動CP（Lv1=10CP〜Lv10=25CP） |
| **能力値の粒度** | ランクのみ（D/C/B/A/S） | ランク＋段階（D-〜A+, S）= 13ステップ |

### ダイスシステム
ランク制ダイスプール：D=1d6 / C=2d6 / B=3d6 / A=4d6 / S=4d6+ボーナス
- 最大値を「達成値」として採用
- 4=部分成功（コストあり）/ 5=成功 / 6=完全成功（特殊効果）/ 1=ファンブル

### 段階システム（＋/−）（v4.0新規）
各ランク（D〜A）に−/無印/+の3段階がある。ダイス数は変わらず、達成値に±1修正。
- 全13ステップ：D- → D → D+ → C- → C → C+ → B- → B → B+ → A- → A → A+ → S
- ファンブル（出目1）/スペシャル（出目6）は出目そのもので判定、段階修正の影響なし
- 段階修正はスキル修正上限（+4）とは**別枠**
- Sランクに段階は存在しない
- キャラクター作成時に任意2つの能力値に+段階を付与
- レベルアップで+1段階（Lv2,4,6,8,9）または1ランク上昇（Lv3,5,7,10）
- 負傷・呪いで−段階が発生（ダウンタイムの休息で解除）
- ダウンタイムの「集中鍛錬」（2回分消費）で+1段階

### セッション三幕構造
1. **調査フェーズ**：解明鍵4つ（①正体 ②核の所在 ③被害パターン ④ルールの全容）を埋める
2. **解明完了宣言**：4鍵→核防御力半減＋浄化+1＋延長権 / 3鍵→通常 / 2鍵以下→−1修正＋護衛防御+2
3. **討伐フェーズ**：核護衛戦。護衛を排除し、核のHPを0にしたら勝利

### 戦闘：核護衛戦（v4.0新設計）

- **護衛**はHP・攻撃力・防御力・行動値・特性を持つフルステータスの敵ユニット
- **核**はHP・防御力を持つ。護衛が全滅するまで直接攻撃不可（解明完了時の例外あり）
- **行動経済**：メイン行動×1＋サブ行動×1＋リアクション×1（ターン外、1ラウンド1回）
- **ダメージ** = 達成値 + 武器修正 − 防御力（護衛は最低1保証、核は最低0）
- **スペシャル**時：ダメージ+1＋対象の防御力を0として扱う

### レベルシステム（v4.0新規）
Lv1〜10。シナリオ完了時にGMがレベルアップを宣言。
- HPボーナス・スキル枠・CP予算がレベルに応じて増加
- Lv3, 5, 7, 10で能力値1つを1ランク上昇（最大A）
- Lv5以上は都市伝説化リスク（恐怖メーター+1〜+2）
- 信念ポイント上限がレベルに応じて減少（Lv1-4=5点、Lv9-10=2点）

### スキルシステム（v4.0 → 6軸制）
クラス制を廃止し、6つの軸からスキルを取得する：

| 軸 | 内容 | スキル数 |
|----|------|----------|
| 共通 | 全員が取得可能 | 6種 |
| 所属 | 祓部/傭兵/無所属ごとに3種 | 計9種 |
| 配属 | 所属内の班・専門・流儀ごとに3種（+能力値1つがB昇格） | 計30種 |
| 覚醒 | 覚醒パターン4種ごとに2種 | 計8種 |
| 背景 | 背景6種ごとに1種（自動取得・スロット不要） | 計6種 |
| 武器技能 | 武器型5種ごとに3種 | 計15種 |

- スキル枠はレベルで増加（Lv1=2枠、Lv10=12枠）
- 行動種別：メイン/サブ/リアクション/パッシブ

### 配属一覧
- **祓部**：古怪班（識B）/ 新怪班（判B）/ 封印班（魂B）/ 機動班（疾B）
- **傭兵**：突撃型（体B）/ 偵察型（察B）/ 技術型（術B）
- **無所属**：野良討伐者（体B）/ 裏社会の住人（疾B）/ 在野研究者（識B）

### 武器型5種
斬撃型 / 打撃型 / 射撃型 / 魔導型 / 体術型
各型に初級〜上級の武器技能3種。武器カスタム（CP制・メーカー補正）は従来どおり独立。

### 《共鳴記録》（変更なし）
6つの感情メーター（恐怖/怒り/哀愁/焦燥/渇望/浄化）。各0〜10。
行動の種類と文脈で上昇するメーターが決まる。10で臨界（コスト+恩恵が発生）。

### 侵食率（Web・公開資料から全削除：2026-04-19）
侵食率は **Webサイト・キャラシUI・プレイヤー向け公開資料（`docs/player/`）からは全削除**。プレイヤーには公開しない方針。
異能・特殊装備のリスクは共鳴メーター（渇望）で管理する。
拡張データブック `docs/rules/expansion.md` は内部資料として残置するが、本ルールは運用上オフになっている。
プレイヤー向けドキュメントで残したキャラ物語の「汚染」は narrative な概念で、機械的な数値は持たない。

### 魔法システム（変更なし）
8つの魔法言語（P / Igniscript / Lupis Surf / Ivyo / NGT / Monyx / P: / P'）
各言語に状況+1修正あり。魔法失敗時：GMが1d6、ランク別閾値超えで怪異誘発。

### 所属特典（変更なし）

|------|---------|
| 祓部 | 識ランク+1段階（3回/セッション）・援軍要請1回 |
| 傭兵 | 装備1ランク上・コネクション+1段階（3回/セッション）・二つ名1つ（常時+1） |

| **連鎖ダメージ** | 突撃型配属スキル「連鎖衝撃」＋打撃型武器技能「粉砕」で余剰ダメージ伝播 |

| **クラス制（祓士/機甲士/解明師）** | 廃止 → 所属×配属×覚醒×背景×武器型の5軸組合せ |

# 公開前 秘匿チェック

CLAUDE.md 鉄則4「秘匿管理」を判定基準リストに落としたもの。**検査と報告のみを行い、削除・修正はユーザー確認後に行う。**

## 検査対象

- `docs/player/` と `docs/legal/` の全ファイル（またはユーザーが指定した変更ファイルのみ）
- サイトに表示されるデータ：`src/data/`・`src/lib/siteDocs.js` 登録文書

## 秘匿トピック（playerとWebに出してはならない）

1. **教団**の内部実態・目的・組織構造（存在の噂レベルは可）
2. **成仏・霧散の原理**の研究内容
3. **祓部の内部対立**の詳細（大祓主と魔導省の対立など。組織の緊張がある程度は可）
4. **雷禽重工・特別研究部門**（存在自体が機密）
5. **怪異核素材**の装備・サイバネ仕様（`docs/rules/expansion.md` の内容全般）
6. **侵食率**の数値・ルール（2026-04-19全削除方針。ロア上の動詞「侵食する」のみ可）
7. GM専用の等級判定基準・シナリオフック・「ドラマの種」節

## 手順

1. 対象ファイルに対し、上記トピックの固有名詞・概念で検索する（例：特別研究部門／怪異核素材／侵食率／成仏の原理）。
2. ヒット箇所ごとに文脈を読み、「噂・伝聞として登場（可）」か「実態・仕様の記述（不可）」かを判定する。
3. 判定に迷う箇所は削除せず「要確認」として残す。

## 出力形式

- **問題なし**：検査対象と検索した観点の一覧
- **混入疑い**：ファイル名・行・引用・該当トピック番号・可否判定の理由
- **要確認**：判断がつかない箇所（ユーザーの判断材料になる情報を添える）
